# C1M Duo starten, ohne etwas zu öffnen

Duo ist ein Kurzbefehl, deshalb kann das iPhone ihn fast von überall starten. Such dir einen oder zwei Wege aus. Jeder ist in unter einer Minute eingerichtet, und du machst es nur einmal.

**Ein Tipp, der überall funktioniert:** Kopiere zuerst den Text, den du prüfen lassen willst. Startest du Duo, ohne etwas zu teilen, erscheint das Fragefeld mit dem bereits kopierten Text darin.

| Wo | So richtest du es ein | Funktioniert auf |
|---|---|---|
| **„Hey Siri, Duo“** | Nichts einzurichten: Siri kennt den Kurzbefehl an seinem Namen. Behalte den Namen „Duo“. | jedem iPhone, iOS 18+ |
| **Teilen-Taste** | Text in einer beliebigen App markieren → Teilen → **Duo**. Schon eingeschaltet. | jedem iPhone, iOS 18+ |
| **Doppeltippen auf die Rückseite** | Einstellungen → Bedienungshilfen → Tippen → **Auf Rückseite tippen** → Doppeltippen → **Duo**. | iPhone 8 und neuer |
| **Kontrollzentrum** | Kontrollzentrum öffnen → **+** (oben links) → Steuerelement hinzufügen → **Kurzbefehle** → **Duo** wählen. | iOS 18+ |
| **Taste auf dem Sperrbildschirm** | Sperrbildschirm lange drücken → Anpassen → Sperrbildschirm → untere Taste antippen → **Kurzbefehl** → **Duo**. | iOS 18+ |
| **Aktionstaste** | Einstellungen → **Aktionstaste** → zu **Kurzbefehl** wischen → **Duo**. | iPhone 15 Pro und neuer |
| **Symbol auf dem Home-Bildschirm** | Kurzbefehle-App → **Duo** gedrückt halten → Teilen → **Zum Home-Bildschirm**. | jedem iPhone |
| **Mac oder iPad** | Die finale Antwort liegt auch in der geteilten Zwischenablage: Drücke auf dem Mac Cmd+V. | gleiche Apple-ID, Handoff an |

## Einen Screenshot von zwei KIs prüfen lassen

Mach den Screenshot, tippe auf die Vorschau, halte den Text gedrückt (Live-Text) → **Alles auswählen** → Teilen → **Duo**. Funktioniert auf jedem iPhone mit iOS 18.

iOS 27 kann einen Kurzbefehl auch von selbst starten, wenn du einen Screenshot machst: Kurzbefehle-App → **Automation** → **+** → **Bildschirmfoto** → **Kurzbefehl ausführen** → **Duo**. Das wurde noch nicht auf einem Handy ausprobiert.
