# Черновик (не опубликован): первая настройка Duo

Для сайта и README. Пока ни откуда не ссылается (D-128).

**Первый запуск — короткая настройка.** Duo скажет вслух, что сейчас одно за другим появятся несколько окон с
кнопками «Разрешать всегда» или «Разрешить». В каждом окне нажмите «Разрешать всегда», а если такой кнопки нет —
«Разрешить». Эту настройку нужно пройти только при первом запуске:
потом Duo больше не спрашивает разрешений.

**Первая настройка для незрячих.** Первый запуск сделайте на разблокированном телефоне с VoiceOver, каждое окно —
«Разрешать всегда». Потом Duo работает голосом через Siri: «Привет, Siri, Duo».
