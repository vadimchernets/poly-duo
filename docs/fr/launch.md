# Interroge C1M Duo sans rien ouvrir

Duo est un raccourci, donc l’iPhone peut le lancer depuis presque partout. Choisis-en un ou deux. Chacun se règle en moins d’une minute, et tu ne le fais qu’une fois.

**Un conseil qui marche partout :** copie d’abord le texte que tu veux faire vérifier. Si tu lances Duo sans rien partager, la zone de question s’ouvre avec ce que tu as copié déjà dedans.

| Où | Comment le régler | Fonctionne sur |
|---|---|---|
| **« Dis Siri, Duo »** | Rien à régler : Siri connaît le raccourci par son nom. Garde le nom « Duo ». | tout iPhone, iOS 18+ |
| **Bouton Partager** | Sélectionne du texte dans n’importe quelle app → Partager → **Duo**. Déjà activé. | tout iPhone, iOS 18+ |
| **Double toucher au dos du téléphone** | Réglages → Accessibilité → Toucher → **Toucher le dos** → Toucher deux fois → **Duo**. | iPhone 8 et ultérieurs |
| **Centre de contrôle** | Ouvre le Centre de contrôle → **+** (en haut à gauche) → Ajouter un contrôle → **Raccourcis** → choisis **Duo**. | iOS 18+ |
| **Bouton de l’écran verrouillé** | Appuie longuement sur l’écran verrouillé → Personnaliser → Écran verrouillé → touche un bouton du bas → **Raccourci** → **Duo**. | iOS 18+ |
| **Bouton Action** | Réglages → **Bouton Action** → fais défiler jusqu’à **Raccourci** → **Duo**. | iPhone 15 Pro et ultérieurs |
| **Icône sur l’écran d’accueil** | App Raccourcis → appuie longuement sur **Duo** → Partager → **Sur l’écran d’accueil**. | tout iPhone |
| **Mac ou iPad** | La réponse finale est aussi dans le presse-papiers partagé : fais Cmd+V sur ton Mac. | même identifiant Apple, Handoff activé |

## Faire vérifier une capture d’écran par deux IA

Fais la capture, touche son aperçu, maintiens le doigt sur le texte (Texte en direct) → **Tout sélectionner** → Partager → **Duo**. Fonctionne sur tout iPhone sous iOS 18.

iOS 27 peut aussi lancer un raccourci tout seul quand tu fais une capture d’écran : app Raccourcis → **Automatisation** → **+** → **Capture d’écran** → **Exécuter le raccourci** → **Duo**. Cela n’a pas encore été essayé sur un téléphone.
