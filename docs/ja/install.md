# Duo のインストール — 2分、技術知識は不要

C1M Duo は iPhone 用の「ショートカット」です。質問をひとつすると、それを2つの AI — ChatGPT と Claude — が12のモードのどれかで一緒に処理します。答えは画面とクリップボードに届きます。

## インストールの前に（最初の一度だけ）

1. **iOS 18 以降の iPhone。** これは Duo の土台になっている「Ask Claude」アクションの公式な最低要件です（Anthropic 自身のドキュメントにも「iOS 18 and later」とあります）。それとは別に、iOS 26 では Apple が iPhone 11 以降、SE（第2世代）以降を対応機種として挙げています。Duo 自体に Apple Intelligence は必要ありません — iOS 18 以降だけです。iPad は iPadOS 18+/26 で動くはずですが、実機での検証はしていません。**Poly Compress** だけは Apple Intelligence 対応のハードウェアが必要です：A17 Pro / M シリーズ以降のチップ（iPhone 15 Pro/Pro Max、16/16e 以降のすべて、M1 以降の iPad または A17 Pro の iPad mini）。
2. **ChatGPT と Claude の App**。App Store からインストールし、どちらもサインインしておいてください。無料アカウントで十分です。無料の Claude は Sonnet 5.5 で、有料プランと同じモデルです。「Ask Claude」アクションは Claude App で選んだモデルを使います。

## インストール（タップ1回）

**いちばん簡単な方法 — iCloud リンク（タップ1回）。** iPhone でリンクをタップ → ショートカット App が開く → **ショートカットを追加**。初回実行時に許可を 4〜6 回たずねられます。そのたびに **常に許可** をタップしてください。

- **Duo:** https://www.icloud.com/shortcuts/d8b35ecacee549e99f21b7c7e1cd18ec
- **Trio、iPhone 15 Pro 以降 — キー不要（3番目の声は Apple Intelligence）:** https://www.icloud.com/shortcuts/92d37480faf44969882f992c08baba7a
- **Trio — 無料のキー（3番目の声）:** https://www.icloud.com/shortcuts/c0988a5ff0f242cb8458f2991eef5b7f

**または、ファイルで：**

1. **`dist/ja/Duo.shortcut`** ファイルを好きな方法で手に入れます：AirDrop、WhatsApp/Telegram、メール、USB メモリ — 何でも構いません。
2. ファイルをタップします。ショートカット App が開いて「Duo」のカードが出るので、**「ショートカットを追加」** をタップ。これでインストール完了です。
   - メッセージ App にファイルが届いた場合は、まずそこでタップし、共有／「次で開く…」を選んで、ショートカットを指定します。
3. **初回実行時：** ショートカットが権限を求めます — 「ChatGPT のアクションを許可しますか？」→ 許可、「…Claude にテキストを送信しますか？」→ **常に許可**、「…クリップボードにコピーしますか？」→ **常に許可**。これは一度きりです。

## ホーム画面のアイコン（30秒、任意）

1. ショートカット App を開く → Duo のタイルを長押し → メニューが出なければタイルの「···」をタップ → 上部の名前 **Duo ⌄** をタップ → **「ホーム画面に追加」**。
2. ブランドのアイコンにしたいときは、サムネイルをタップ → 「イメージ」タブ →「写真/ファイルを選択」→ `assets/poly.jpg` を選びます（ショートカットと一緒に iPhone に送っておいてください）。
3. **「追加」** をタップ。ホーム画面に Duo のアイコンが出て、タップ1回で起動できます。音声なら「Hey Siri、Duo」。

## 使い方

アイコンをタップ →「Duo に何を聞きますか？」→ 質問を入力 →「完了」→ モードを選ぶ。メニューは2階層です：よく使う5つのモードが上、それ以外は **📂 その他…** の中（何も削られていません — たまにしか使わないモードがタップ1回ぶん遠いだけです）。その他… には **ℹ️ Duo とは** も入っています — 各モードを端末内で無料で説明してくれます。モード選びで迷ったら開いてください — メッセージは1通も使いません。

**メインメニュー（よく使うモード）：**

| モード | 何が起きるか | コスト |
|---|---|---|
| **⚖️ 批評 · 3✉** | ChatGPT と Claude がそれぞれ相手の答えを見ずに答え、Claude が両方を見比べて最終回答を出します。冒頭は3つのブロックです：それぞれ独立に一致した点 / 一致しなかった点 / 自分で確かめること。ふだん使いの定番。 | 3通 |
| **🩺 助言 · 1✉** | Claude が「あなたの」書き上げた文章を、書き換えずに講評します：1行の総評、いちばん強い反論から順に、確かめ直すべき点。いちばん安いモード。 | 1通 |
| **👀 並べて比較 · 2✉** | 二人が独立に答え、その回答を隣り合わせに並べます。 | 2通 |
| **🔀 統合 · 3✉** | 互いを見ずに両方が答え、「軸 + 差分」の形にまとめます。どちらを軸にするか聞かれます：Claude（事実・構成）か ChatGPT（トーン・創造性）か。大事な用件に。 | 3通 |
| **🧭 おまかせ · +1✉** | どのモードがいいか分からないときは、ChatGPT が選んでくれます（+1通）。そのあと Duo が同じ質問で再スタートするので、勧められたモードを選べます。 | 1通 + そのモード |

**📂 その他…（たまに使うモード + 無料のヘルプ）：**

| モード | 何が起きるか | コスト |
|---|---|---|
| **⚔️ 決断 · 3✉** | 素早い見方（ChatGPT）と慎重な見方（Claude）をぶつけ、そのあと審判が最初の一歩とリスクを整理します。決めるときに。 | 3通 |
| **🗺 論点マップ · 3✉** | 互いを見ずに両方が答え、それを地図にします：一致する点、食い違う点、見落とし、確かめるべきこと。結論は押しつけません — 決めるのはあなたです。 | 3通 |
| **🥊 討論 · 4✉** | 草案、弱点を突く反対役、改稿、そして判定。いちばん難しい問題に。 | 4通 |
| **❓ 明確化 · 2✉** | まず ChatGPT が足りないことを聞き返し → 出てきた入力欄にあなたが答え → Claude が的確に答えます。あいまいな質問に。実行の途中で画面に触ることが前提の唯一のモードですが、触るのはその入力欄だけで、他はいっさい触りません。 | 2通 |
| **➕ 差分 · 2✉** | Claude が軸になる回答を書き → ChatGPT は改良点の箇条書きだけを返します（全部書き直しません）。メッセージ数を節約したいときの、統合の安い代わり。 | 2通 |
| **🎨 画像 · 2–3✉** | 何を描くかを説明 → 2人の AI 絵描きが互いを見ずにスケッチします（ベクター SVG、それぞれ新しいセッションで — 相手をのぞき見しません）→ 2つのスケッチが並んだページが開きます。◆ CLAUDE と ◆ CHATGPT から好きな方を選んでください（スケッチのみ · 2✉ か、比較する審判の判定つき · 3✉ かを聞かれます — 審判が比べるのはスケッチのコードで、描画そのものはあなたの目で見て分かります）。画像は保存され（ファイル → iCloud Drive → ショートカット → `Duo-image.html`）、SVG コードはクリップボードに入ります：任意の変換ツールやサイトに貼れば、好きなサイズの画像ファイルになります。 | 2〜3通 |
| **ℹ️ Duo とは** | Duo が何なのか、どのモードをいつ使うのかを画面で説明します — AI は一切呼びません。そこから「🔁 別のモード」を選べば、同じ質問のままモード選択に戻れます。 | 0通 |

**メニューそのものへの近道**（任意）：**Poly Quiet** を手元に置いておくと便利です — タップ1回で走る批評そのままの実行で、モード選択すらありません（結果は画面を出さずにクリップボードと記録へ直行）。あるいは **Poly Voice** — 同じことを音声で行い、結果を読み上げます。どちらのアイコンも Duo と同じようにホーム画面に置けるので、フルメニューの隣に「即実行ボタン」が並びます。

料金はメニューにそのまま表示されます（✉ のマーク）。実行中は進捗の通知が届きます —「[2/4]…」。記録にはモードと途中の生の回答が残るので、最終結果が途中で切れても草案は失われません。最終回答は共有ボタン付きで全画面で開きます（クイックルック）。

**2つの段階。** 段階1が中核です：完全に自動で動く Duo のデュオと、下に挙げる自動のコンパニオン群 — 迷わず入れてください、革新の中身はここにあります。段階2は上級者向けの PRO 拡張です：**🎼 Poly Multi**（米中10種の AI を手作業で回す合唱と、東西の統合）は別配布で、中核の体験には必須ではありません — 基本に慣れてから手を出してください。

**自動で動く Duo のコンパニオン**（ソースからのビルドのみ）：**Poly Voice** — タップして口述すると批評のパイプラインが走り、答えを読み上げます（歩きながら・料理しながらに便利）。**Poly Photo** — 写真や PDF を共有すると、端末内の OCR が文字を読み取り（無料・通信なし）、そのまま Duo に渡します。**Poly Quiet** — 批評と同じパイプラインですが通知も最終画面もなし：結果はクリップボードと記録だけに入ります（裏で素早く回したいときに）。**Poly Compress**（Apple Intelligence 対応機種のみ：iPhone 15 Pro 以降、16/16e/17 の全ラインアップ）— 長い文章を選択 → 共有 → Compress：Apple の無料のオンデバイスモデルが縮めてから Duo を自動で起動します（長文でのタイムアウト対策）。 コンパニオンはソースからビルドする人向けで、iCloud のリンクにはまだ入っていません。メインのショートカットを「Poly」という名前で呼び出すので、自分のショートカットの名前を「Poly」にするか、各コンパニオンの「ショートカットを実行」ステップを書き換えてください。

モードを選んだ直後に **状況の通知**（「今なにが起きていて、どれくらい待つか」）が届きます。そこからおよそ1〜2分で、答えが画面とクリップボードに現れます。よくある20以上の用途向けの言い回しは `recipes.md` にあります。最終回答は必ず要点1行から始まり、「確信度: 高/中/低」で終わります。**ショートカットが動いている間は、iPhone を放っておいてください** — 画面に触ると中断されます（黙って止まったように見えたら、もう一度実行するだけで大丈夫です）。例外は **❓ 明確化** です：設計どおり2つ目の画面を開いて、追加の質問に答えるよう求めてきます（あるいは「スキップ」と入力）— 不具合ではなく、流れの一部です。答えればショートカットは自分で続きます。

## 使いこなしのコツ

- **どのアプリからでも：** テキストを選択 → 共有 → Duo — 質問欄にはもうそのテキストが入っています。「翻訳して／確認して／説明して」と足して実行するだけです。
- **記録：** 実行のたびに `Duo-journal.md` に追記されます（ファイル → iCloud Drive → ショートカット）。質問と結論の履歴がひとつの場所にまとまります。初回実行時は、ファイルへのアクセスを **常に許可** にしてください。
- **手を使わない起動：** 設定 → アクションボタン →「ショートカットを実行」→ Duo。あるいは背面のダブルタップ：設定 → アクセシビリティ → タッチ → 背面タップ → Duo。音声なら「Hey Siri、Duo」。
- **入口をもっと増やす：** ホーム画面やロック画面のウィジェット（ホーム画面を長押し → + → ショートカット → Duo）、コントロールセンター（設定 → コントロールセンター →「ショートカット」を追加）、机や車に貼った NFC タグ（ショートカット → オートメーション → NFC → Duo を実行）。
- **写真をデュオに渡す：** 本筋は **Poly Photo**（写真/PDF を共有 → OCR → Duo が自動で立ち上がります）。画像そのものを*見て*ほしいとき（写っている文字ではなく）は、Claude のカメラウィジェット → 分析 → コピー → そのテキストを Duo に共有してください。
- **自分の文章を点検する：** どこでも下書きを選択 → 共有 → Duo → **🩺 助言** モード — 書き換えずに講評します（勝手に共著者になったりしません）。
- **iPhone 15 Pro 以降なら：** ショートカットに「モデルを使用」アクション（Apple Intelligence、無料、インターネット不要）があり、Duo を拡張できます — たとえばモードの自動選択に。iPhone 14 以前ではこのアクションは使えませんが、Duo はそれなしで問題なく動きます。
- **すぐ聞き取りを始める（任意）：** ショートカットの編集画面で最初の「入力を要求」アクションを展開し、すぐに口述を始めるスイッチをオンにします — するとアイコンをタップした瞬間から質問の聞き取りが始まります。既定ではオフです。入力したテキストにも共有シートにも、そのほうが都合がよいからです。
- 何も開かずに Duo を起動する方法（Siri、背面タップ、ロック画面、アクションボタン）：[launch.md](launch.md) を参照してください。

## iCloud について — 有料プランは不要です

Duo に有料の iCloud は要りません。中心の流れ（質問 → 2つの AI → 画面とクリップボードに答え）は iCloud にまったく触れません。使うのは任意の便利機能2つだけ：実行の記録と画像ファイルで、どちらもキロバイト単位です。どの Apple ID にもついてくる無料の 5 GB で何十年ぶんもまかなえます。iCloud Drive がオフでも容量がいっぱいでも、答えは変わらず画面とクリップボードに届きます（これは設計上の保証です）— 記録の書き込みが飛ばされるだけです。そもそも記録が要らない場合は、下のプライバシーをご覧ください。

## プライバシー

`Duo-journal.md` は、すべての質問と回答を iCloud Drive にプレーンテキストで保存します。履歴が要らない場合は、ショートカットの編集画面で記録のアクションを削除してください。すでに残っているものを消すには、ファイル App で `Duo-journal.md` を削除します。記録が大きくなりすぎたら、ファイル名を変えるだけで構いません（たとえば `Duo-journal-8gatsu.md` に）— 次の実行で新しいファイルが自動で作られます。

## うまくいかないときは

- **アクション一覧に「Ask Claude」がない：** Claude App と iOS を更新してください（iOS 18 以降）。
- **答えが空：** ChatGPT と Claude の App を一度ずつ開いてから、もう一度実行してください。
- **許可の確認が、タップする前に消えた：** もう一度実行して、すぐに **Always Allow** をタップしてください。
- **ChatGPT が「You are logged out」と言う**（どう見てもログインしているのに）— ChatGPT App を開いて、閉じて、Duo をもう一度実行してください。既知の不具合で、いつもこれで直ります。
- **Claude が「This model isn't available right now」と言う** — 無料 Claude の1日の上限に達したか、Claude App で選んだモデルがあなたのプランにありません。Claude App で Sonnet を選ぶか、上限のリセットを待ってください。その間は Trio が無料キーの AI で検証します。
- **Claude が黙る／長い質問で回答が空になる** — Claude のアクションにはタイムアウトがあり、Claude が書き終える前に制御を返してしまうことがあります。その間も Claude は自分の App の中で回答を書き続けています。Claude を開けば答えはそこにあるので、App のボタンでコピーしてください。次回のために：質問は短いほうが確実に返ってきます。まるごと失敗したときは、App スイッチャーからショートカットをスワイプで終了させて、もう一度実行します。
- **Duo を誰かに渡すとき：** `Duo.shortcut` は zip にせず、単体のファイルとして送ってください（スマホでの zip は手数が増えます）。Telegram なら、ファイルを長押し → 共有／ファイルに保存で、シングルタップは使いません。
- **Duo の名前は変えないでください。** Siri（「Hey Siri、Duo」）と「🔁 別のモード」ボタンは「Duo」という正確な名前で探します。名前を変えると（あるいは再読み込みして「Duo 1」ができてしまうと）、これらの経路が黙って動かなくなります。入れ直して重複ができたら、古いほうを削除し、「Duo」という名前をちょうど1つにしてください。（例外：ソースからビルドしたコンパニオンは「Poly」を探します — 上のコンパニオンの段落を参照。）
- **思ったより回答が弱い** — アクションは Claude App で既定に設定されているモデルをそのまま使います：Claude を開いてモデルを切り替え、閉じてから Duo を実行してください。大事な実行の前に Claude のヘッダーでモデルを確かめる — これを習慣にすると安心です。
- **共有したのがリンクだけで何も起きなかった** — アクション自体は Web ページを取りに行きません：ページを開いて本文の一部を選択し、そのテキストを共有してください。
- **おまけ：** 最終回答は共有クリップボード（ユニバーサルクリップボード）にも入ります — Mac や iPad なら、iPhone に触らずに Cmd+V で貼り付けられます。
- **iOS の大きなアップデートのあと**（たとえば iOS 27 へ）は、批評をひとつテスト実行してください。ショートカットの大きな更新では権限を聞き直されたり、余分な「完了」カードが出たりすることがあり、1回の実行でそれが表に出て片づきます。
- メッセージの消費は各サービスの **サブスクリプション** から引かれ（API ではありません）、普段のチャットと同じ上限を共有します。使われるモデルは、それぞれの App で既定に設定されているものです。

## 最終回答のあとに来るもの

最終画面の下で、Duo が尋ねます：**「✅ 完了」** か **「🔁 別のモード — 同じ質問」**。2つ目を選ぶと、質問を入力済みの状態で Duo が再スタートし（編集もできます）、別のモードを選べます。批評を実行して、そのまま同じ質問を論点マップにかける — 打ち直さずにこれができるので便利です。
