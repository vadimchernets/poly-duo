# Duo のレシピ — 何を聞き、どのモードを使うか

C1M Duo は何でも屋です：どんな用件も、適切な言い回しと適切なモードの組み合わせに落ち着きます。以下は実際に試したレシピ集です。すでにある文章を扱うときの最短ルート：**テキストを選択 → 共有 → Duo** — そのまま質問欄に入るので、あとは前に指示を足すだけです。

| 用件 | 質問に書くこと | モード |
|---|---|---|
| 送信前にメールを見直す | 「このメールを確認して良くしてください。あたたかいビジネスの調子は保ったまま：[本文]」 | ⚖️ 批評 · 3✉（もう完成していて書き換えてほしくない？ そのときは 🩺 助言 を — 下を参照） |
| 難しい／感じの悪いメッセージに返信する | 「届いたメッセージです。調子と意図を読み解いて、違う調子の返信を3案ください：[本文]」 | ⚖️ 批評 · 3✉ |
| コードを書かせて、レビューさせる | 「[必要なもの]を書いてください。条件：…」 | ⚖️ 批評 · 3✉（🥊 討論 · 4✉ は重要なコードだけ。穴を探させたいときに限ります） |
| 既存のコードをレビューする | 「バグ・リスク・改善点を挙げてください：[コード]」 | 👀 並べて比較 · 2✉ |
| 決断する（買う／乗り換える／出す？） | 「[案・決断]をすべきでしょうか？ 前提：…」 | ⚔️ 決断 · 3✉ |
| 案件や取引のリスクを見積もる | 「[対象]にどんなリスクがあり、どう塞げばいいですか？」 | ⚔️ 決断 · 3✉ |
| 文章やニュースの事実確認 | 「この主張に事実の誤りがないか確認してください：[本文]」 | 🔀 統合 · 3✉ |
| 重い問い（医療／法律／お金） | そのまま聞く | 🔀 統合 · 3✉（🥊 討論 は代わりにはなりません — あれは結論をわざと負荷にかけたいときのものです） |
| 新しい分野を手早くつかむ | 「専門外の人向けに、水増しせずに説明してください：[テーマ]」 | ⚖️ 批評 · 3✉ |
| 学んで、自分で確認する | 「[テーマ]を説明し、答え付きの確認問題を3つください」 | ⚖️ 批評 · 3✉ |
| 打ち合わせや交渉の準備 | 「[相手]と[テーマ]について打ち合わせます。こちらが聞くべき質問と、想定される反論を答え付きで挙げてください」 | ⚔️ 決断 · 3✉ |
| 名前・キャッチコピー・案出し | 「[対象]の案を作風を変えて10個ください。そのあと理由付きで上位3つを選んでください」 | 👀 並べて比較 · 2✉ |
| 記事を要約する | 記事を選択 → 共有 → 「要約してください：要点と結論」 | ⚖️ 批評 · 3✉ |
| 一日の段取り／やることの優先順位づけ | 「やることはこれです：[…]。優先順位をつけて、進める順番を提案してください」 | ⚔️ 決断 · 3✉ |
| 翻訳して整える | 「[言語]に訳して、文体を整えてください：[本文]」 | ⚖️ 批評 · 3✉ |
| アイデア出し | 「この問題に、ありきたりでない解決案を5つ：[…]。そのあと、どれが現実的か評価してください」 | ⚖️ 批評 · 3✉（これは「出して絞る」であって「負荷試験」ではありません — 討論は要りません） |
| 長い説明 → 短いまとめ | 「[…]を詳しく説明し、最後に一文ずつ3点にまとめてください」 | ⚖️ 批評 · 3✉ |
| 気まずいメッセージ → 返信の下書き | やり取りを選択 → 共有 → 「調子を読み解いて、返信を提案してください」 | ⚔️ 決断 · 3✉ |
| 「自分の」文章を書き換えずに点検する | 自分の下書きを選択 → 共有 →（何も足さない） | 🩺 助言 · 1✉ |
| 意見の割れる話題 — 実際のところ何が本当か | そのまま聞く — 一致と食い違いの地図が返り、結論は押しつけられません | 🗺 論点マップ · 3✉ |
| 漠然とした質問。自分でも何が欲しいか分からない | そのまま聞く — まず聞き返しが来ます | ❓ 明確化 · 2✉ |
| ロゴ・図解・グリーティングカード・イラスト | 「[何を、どんな作風で]描いてください」 — 選べるベクタースケッチ2案 | 🎨 画像 · 2–3✉ |
| 書類・標識・メニューの写真 | 写真を共有 → Poly Photo（あとは文字認識が引き受けます） | Poly Photo コンパニオン |
| 画面が小さい／移動中 | 音声で聞く — 答えは読み上げられ、テキストはクリップボードに入ります | Poly Voice コンパニオン |
| どのモードを選べばいいか分からない | そのまま聞く — モードは自分で選ばない | 🧭 おまかせ · +1✉（ChatGPT が1つ勧めます。Duo は同じ質問で再スタートします） |
| メッセージの残りが心もとないが、二つの見方は欲しい | そのまま聞く | ➕ 差分 · 2✉（🔀 統合 の安い代わり：Claude の軸 + ChatGPT の改良点リスト — 3通ではなく2通） |

## 使いこなしのメモ

- **討論は珍しい道具であって、既定ではありません。** 結論をわざと壊しにかかってほしいときのために取っておいてください：重要なコード、間違いが高くつく決断。ふだんの書きものは批評か助言で、重い問いは統合で扱います。
- **正しさがいちばん大事なときは、まず両方に答えさせましょう。** ⚖️ 批評では、Claude は ChatGPT の答えを読んでから確認します。答えを見たあとの確認者は、その答えに賛成しやすくなります。そのため「両方が同意」という表示は、見た目ほど重くありません。👀 並べて比較と 🔀 統合では、どちらも相手の答えを見る前に自分で答えます。そこで意見が一致したときは、その一致のほうが重みを持ちます。
- 質問欄のキーボードにある **マイクのキー** を押せば、設定なしでそのまま音声入力できます。
- 質問の末尾に足す **ひとこと** は効きます：「簡潔に答えて」「詳しく」「箇条書きだけで」— モデルはちゃんと従います。
- よく使うレシピには、**小さな専用ショートカット** を作れます：用件をあらかじめ書いたテキストのブロックに、Duo を指定した「ショートカットを実行」を続けるだけです（その用件が入力済みの質問になります）。
- 実行結果はすでに **クリップボード** に入っています — メールやチャットにそのまま貼れます — そして **記録** `Duo-journal.md` にも保存されます。
