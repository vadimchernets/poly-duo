# 何も開かずに C1M Duo に聞く

Duo はショートカットなので、iPhone のほぼどこからでも起動できます。このうち1つか2つを選んでください。どれも設定は1分もかからず、一度やれば済みます。

**どこでも使えるコツ：** 先に、チェックしてほしい文章をコピーしておきます。何も共有せずに Duo を起動すると、コピーした内容がすでに入った状態で質問欄が開きます。

| 起動する場所 | 設定のしかた | 使える環境 |
|---|---|---|
| **「Hey Siri、Duo」** | 設定は不要です。Siri はショートカットを名前で知っています。名前は「Duo」のままにしてください。 | すべての iPhone、iOS 18 以降 |
| **共有ボタン** | 任意の App でテキストを選択 → 共有 → **Duo**。最初からオンです。 | すべての iPhone、iOS 18 以降 |
| **背面のダブルタップ** | 設定 → アクセシビリティ → タッチ → **背面タップ** → ダブルタップ → **Duo**。 | iPhone 8 以降 |
| **コントロールセンター** | コントロールセンターを開く → 左上の **＋** → コントロールを追加 → **ショートカット** → **Duo** を選ぶ。 | iOS 18 以降 |
| **ロック画面のボタン** | ロック画面を長押し → カスタマイズ → ロック画面 → 下のボタンをタップ → **ショートカット** → **Duo**。 | iOS 18 以降 |
| **アクションボタン** | 設定 → **アクションボタン** → **ショートカット** までスワイプ → **Duo**。 | iPhone 15 Pro 以降 |
| **ホーム画面のアイコン** | ショートカット App → **Duo** を長押し → 共有 → **ホーム画面に追加**。 | すべての iPhone |
| **Mac や iPad** | 最終回答は共有クリップボードにも入っています。Mac で Cmd+V を押してください。 | 同じ Apple ID、Handoff オン |

## スクリーンショットを2つの AI でチェックする

スクリーンショットを撮り、プレビューをタップして、テキストを長押し（ライブテキスト）→ **すべてを選択** → 共有 → **Duo**。iOS 18 のすべての iPhone で使えます。

iOS 27 では、スクリーンショットを撮ったときにショートカットを自動で起動することもできます。ショートカット App → **オートメーション** → **＋** → **スクリーンショット** → **ショートカットを実行** → **Duo**。これはまだ実機で試していません。
