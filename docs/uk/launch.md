# Спитати C1M Duo, нічого не відкриваючи

Duo — це швидка команда, тож iPhone може запустити її майже звідусіль. Оберіть один-два способи. Кожен налаштовується менше ніж за хвилину, і робите це лише раз.

**Порада, що працює скрізь:** спершу скопіюйте текст, який хочете перевірити. Якщо запустити Duo, нічим не ділячись, з'явиться поле питання, в якому вже буде те, що ви скопіювали.

| Звідки | Як налаштувати | Працює на |
|---|---|---|
| **«Hey Siri, Duo»** | Налаштовувати нічого: Siri знає команду за назвою. Залиште назву «Duo». | будь-який iPhone, iOS 18+ |
| **Кнопка «Поділитися»** | Виділіть текст у будь-якому застосунку → «Поділитися» → **Duo**. Уже ввімкнено. | будь-який iPhone, iOS 18+ |
| **Подвійне торкання задньої панелі** | Параметри → Універсальний доступ → Дотик → **Торкання задньої панелі** → Подвійне торкання → **Duo**. | iPhone 8 і новіші |
| **Пункт керування** | Відкрийте Пункт керування → **+** (угорі ліворуч) → Додати елемент керування → **Команди** → оберіть **Duo**. | iOS 18+ |
| **Кнопка на екрані блокування** | Затримайте палець на екрані блокування → Налаштувати → Екран блокування → торкніться нижньої кнопки → **Команда** → **Duo**. | iOS 18+ |
| **Кнопка дії** | Параметри → **Кнопка дії** → прогорніть до **Команда** → **Duo**. | iPhone 15 Pro і новіші |
| **Іконка на екрані «Додому»** | Застосунок «Команди» → затримайте палець на **Duo** → «Поділитися» → **На екран "Додому"**. | будь-який iPhone |
| **Mac або iPad** | Фінальна відповідь є й у спільному буфері обміну: натисніть Cmd+V на Mac. | той самий Apple ID, Handoff увімкнено |

## Перевірити скриншот двома ШІ

Зробіть скриншот, торкніться його мініатюри, затримайте палець на тексті (Live Text) → **Вибрати все** → «Поділитися» → **Duo**. Працює на будь-якому iPhone з iOS 18.

iOS 27 може й сама запускати команду, коли ви робите скриншот: застосунок «Команди» → **Автоматизація** → **+** → **Скриншот** → **Запустити команду** → **Duo**. На телефоні це ще не пробували.
