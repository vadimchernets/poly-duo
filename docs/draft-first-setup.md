# Draft (not published): Duo's first setup

For the site and README. Not linked from anywhere yet (D-128).

**The first run is a short setup.** Duo says aloud that several windows will appear, one after another, with the
buttons «Always Allow» or «Allow». In each window, tap «Always Allow», or «Allow» if there is no such button. If
tapping is hard, ask someone to help. You only go through this setup on the first run: after that, Duo does not ask
for permissions again.

**First setup for blind users.** Do the first run on an unlocked phone with VoiceOver on, and answer every window
with «Always Allow». After that, Duo works by voice through Siri: «Hey Siri, Duo».
