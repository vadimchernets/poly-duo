# Duo 설치하기 — 2분, 기술 지식은 필요 없어요

C1M Duo는 iPhone용 «단축어»예요. 질문을 하나 하면 두 AI, 곧 ChatGPT와 Claude가 열두 가지 모드 중 하나로 함께 처리해요. 답은 화면과 클립보드에 도착해요.

## 설치하기 전에 (한 번만)

1. **iOS 18 이상의 iPhone.** Duo의 바탕이 되는 «Ask Claude» 동작의 공식 최소 조건이에요(Anthropic 자체 문서에 «iOS 18 and later»라고 적혀 있어요). 별개로, iOS 26에서 Apple은 iPhone 11 이상, SE 2세대 이상을 지원 기기로 꼽아요. Duo 자체는 Apple Intelligence가 필요 없고 iOS 18 이상이면 돼요. iPad는 iPadOS 18+/26에서 동작할 것으로 예상하지만 실제로 써 본 적은 없어요. 동반 단축어 **Poly Compress**는 Apple Intelligence를 지원하는 하드웨어가 꼭 필요해요: A17 Pro / M 시리즈 이상의 칩(iPhone 15 Pro/Pro Max, 16/16e 이후의 모든 모델, M1 이상의 iPad 또는 A17 Pro 탑재 iPad mini).
2. **ChatGPT 앱과 Claude 앱.** App Store에서 설치하고 둘 다 로그인해 두세요. 무료 계정으로 충분해요. 무료 Claude도 유료 플랜과 같은 Sonnet 5.5 모델을 쓰고, Ask Claude 동작은 Claude 앱에서 고른 모델을 써요.

## 설치하기 (한 번 탭)

### 가장 쉬운 방법 — iCloud 링크 (한 번 탭)

iPhone에서 링크를 탭하면 → 단축어 앱이 열려요 → **단축어 추가**. 처음 실행할 때 단축어가 권한을 4–6번 물어봐요. 매번 **항상 허용**을 탭하세요.

- **Duo:** https://www.icloud.com/shortcuts/ff7bff3172e34e43923a3ce16dea51dc
- **Trio** (세 번째 목소리, 아래 참고): https://www.icloud.com/shortcuts/0df9f941045d4c3a8e43bef02c01c35b

### 백업 — 파일

서명된 `Duo.shortcut`과 `Trio.shortcut` 파일은 [polyhelper.ai/duo/](https://polyhelper.ai/duo/)와 [GitHub 릴리스](https://github.com/vadimchernets/poly-duo/tree/main/releases)에 있어요. 아니면 이렇게 하세요.

1. **`Duo.shortcut`** 파일을 어떤 방법으로든 받으세요: AirDrop, WhatsApp/Telegram, 이메일, USB 드라이브 — 방법은 상관없어요.
2. 파일을 탭하세요. 단축어 앱이 «Duo» 카드와 함께 열리면 **단축어 추가**를 탭하세요. 끝, Duo가 설치되었어요.
   - 파일이 메신저 앱으로 왔다면, 먼저 그 앱에서 탭하고 공유/«다음으로 열기…»를 고른 뒤 단축어를 선택하세요.
3. **처음 실행:** 단축어가 권한을 물어봐요 — «ChatGPT 동작을 허용하시겠습니까?» → 허용, «…Claude에 텍스트를 보내시겠습니까?» → **항상 허용**, «…클립보드에 복사하시겠습니까?» → **항상 허용**. 이 과정은 한 번만 있어요.

## 홈 화면 아이콘 (30초, 선택 사항)

1. 단축어 앱을 열고 → Duo 타일을 길게 누르세요 → 메뉴가 나오지 않으면 타일의 «···»를 탭하세요 → 위쪽의 이름 **Duo ⌄**를 탭하세요 → **«홈 화면에 추가»**.
2. 전용 아이콘을 쓰고 싶다면 썸네일을 탭하세요 → «이미지» 탭 → «사진/파일 선택» → `Duo.jpg`를 고르세요(단축어와 함께 휴대폰으로 보내 두세요).
3. **추가**를 탭하세요. Duo 아이콘이 홈 화면에 나타나요 — 한 번 탭하면 실행돼요. 음성으로는 «Hey Siri, Duo.»

## 사용 방법

아이콘을 탭하세요 → «Duo에게 할 질문은?» → 질문을 입력하세요 → «완료» → 모드를 고르세요. 메뉴는 두 단계예요. 위쪽에 흔히 쓰는 모드 여섯 개가 있고, 나머지는 모두 **📂 더 보기…** 안에 있어요(없어진 것은 없고, 드물게 쓰는 모드는 한 번 더 탭하면 돼요). 더 보기에는 **ℹ️ Duo란**도 있어요. 모든 모드를 설명하는 무료 기기 내 안내인데, 메시지를 하나도 쓰지 않아요. 모드 고르는 화면에서 헷갈린다면 열어 보세요.

**메인 메뉴(흔히 쓰는 모드):**

| 모드 | 하는 일 | 비용 |
|---|---|---|
| **⚖️ 검토 · 3✉** | ChatGPT와 Claude가 서로 보지 않고 각자 답하고, Claude가 두 답을 비교해서 최종본을 내놓아요. 맨 앞에 블록이 세 개 나와요: 따로 답했는데 일치한 것 / 일치하지 않은 것 / 직접 확인할 것. 매일 쓰는 기본 모드예요. | 메시지 3개 |
| **🤝 합의까지 토론 · 3–8✉** | 정답이 없는 삶의 선택(«뭘 고를까», «동의할까»)용이에요. ChatGPT가 한쪽 입장을 잡고, Claude가 반론하고, ChatGPT가 답해요 — 한쪽이 솔직하게 양보할 때까지 최대 3라운드. 그다음: 합의한 것, 아직 다투는 것, 직접 정할 것. | 메시지 3–8개 |
| **🩺 조언자 · 1✉** | Claude가 여러분이 이미 쓴 글을 고쳐 쓰지 않고 검토해요: 한 줄 판정, 가장 강한 반론을 먼저, 다시 확인할 것. 가장 저렴한 모드예요. | 메시지 1개 |
| **👀 나란히 보기 · 2✉** | 둘이 따로 답하고, 답이 나란히 놓여요. | 메시지 2개 |
| **🔀 종합 · 3✉** | 둘이 서로 보지 않고 답한 다음 «기준 + 보탬» 결과로 합쳐져요. 기준을 누가 잡을지 물어봐요: Claude(사실/구조) 또는 ChatGPT(어조/창의성). 중요한 일에 알맞아요. | 메시지 3개 |
| **🧭 자동 · +1✉** | 어떤 모드를 쓸지 모르겠나요? ChatGPT가 하나 골라 주고(+1 메시지), Duo가 같은 질문으로 다시 시작하니 추천된 모드를 고르면 돼요. | 메시지 1개 + 해당 모드 |

**📂 더 보기… (가끔 쓰는 모드 + 무료 도움말):**

| 모드 | 하는 일 | 비용 |
|---|---|---|
| **⚔️ 결정 · 3✉** | 빠른 견해(ChatGPT)와 신중한 견해(Claude)가 만나고, 심판이 첫 단계와 위험을 정리해요. 결정을 내릴 때 써요. | 메시지 3개 |
| **🗺 쟁점 지도 · 3✉** | 둘이 서로 보지 않고 답한 다음 지도로 정리해요: 어디서 같은지, 어디서 갈리는지, 놓친 점, 확인할 것. 결론을 억지로 내지 않아요 — 정하는 것은 여러분이에요. | 메시지 3개 |
| **🥊 논쟁 · 4✉** | 초안, 약점을 찾는 반대편, 수정, 그리고 심판의 판정. 가장 어려운 문제용이에요. | 메시지 4개 |
| **❓ 되묻기 · 2✉** | ChatGPT가 먼저 부족한 점을 물어요 → 뜨는 창에서 답해요 → Claude가 정확하게 답해요. 막연한 질문용이에요. 실행 도중 화면을 만져야 하는 유일한 모드지만, 그 모드 자체의 대화 상자에서만이에요. | 메시지 2개 |
| **➕ 보탬 · 2✉** | Claude가 기준 답을 쓰고 → ChatGPT는 개선점의 글머리 기호 목록만 돌려줘요. 전체를 다시 쓰지 않아요. 메시지 예산이 빠듯할 때 종합 대신 쓰는 더 저렴한 방법이에요. | 메시지 2개 |
| **🎨 그림 · 2–3✉** | 그릴 것을 설명하세요 → 두 AI 화가가 서로 보지 않고 스케치해요(벡터 SVG, 각자 깨끗한 세션에서 — 서로 훔쳐보지 않아요) → 스케치 두 장이 나란히 놓인 페이지가 열려요, ◆ CLAUDE와 ◆ CHATGPT — 하나를 고르세요(스케치만 · 2✉ 또는 + 비교 심판의 판정 · 3✉ 중에서 물어봐요 — 심판은 스케치 코드를 비교하고, 렌더링된 그림은 여러분이 이미 직접 볼 수 있어요). 그림은 파일 → iCloud Drive → Shortcuts → `Duo-image.html`에 저장되고, SVG 코드는 클립보드로 와요. 아무 변환기나 사이트에 붙여 넣으면 원하는 크기의 이미지 파일을 얻을 수 있어요. | 메시지 2–3개 |
| **ℹ️ Duo란** | Duo가 무엇이고 언제 어떤 모드를 쓰면 좋은지 화면으로 설명해요 — AI 호출은 없어요. 거기서 «🔁 다른 모드»를 누르면 같은 질문으로 모드 선택으로 돌아가요. | 메시지 0개 |

**메뉴로 바로 가는 지름길**(선택 사항): **Poly Quiet** 동반 단축어를 가까이 두세요 — 한 번 탭으로 끝나는 완성된 검토 실행이고 모드 선택 화면이 아예 없어요(결과는 곧바로 클립보드와 저널로 가고 화면은 뜨지 않아요). 또는 **Poly Voice** — 같은 일을 음성으로 하고 결과를 소리 내어 읽어 줘요. 둘 다 Duo처럼 아이콘을 홈 화면에 둘 수 있어서, 전체 메뉴 옆에 «빠른 버튼»이 생겨요.

가격은 메뉴에 바로 표시돼요(✉ 아이콘). 실행되는 동안 진행 알림이 와요 — «[2/4단계]…». 저널에는 모드와 중간 원본 답이 모두 기록되므로, 최종 결과가 잘려도 초안은 사라지지 않아요. 최종 답은 공유 버튼이 있는 전체 화면(Quick Look)으로 열려요.

**두 단계.** 1단계가 핵심이에요: Duo와 아래의 동반 단축어는 한 번 탭하면 스스로 돌아가요 — 여기서 시작하세요. 이것이 중심이에요. 2단계는 **🎼 Poly Multi**예요: 같은 듀오에 가진 다른 AI를 반자동으로 더하는 방식이에요 — Duo가 프롬프트를 쓰고, 앱을 하나씩 안내하고, 모든 것을 한 문서로 병합하며, 여러분은 붙여 넣고, 보내고, 복사해요. 직접 물어보는 것의 절반 정도 일이에요. 핵심과 함께 제공되니, 듀오가 익숙해지면 써 보세요.

**자동 Duo 동반 단축어**(포함): **Poly Voice** — 탭하고, 말하면, 검토 파이프라인이 돌아가고, 답을 소리 내어 읽어 줘요(걷거나 요리할 때 좋아요). **Poly Photo** — 사진이나 PDF를 공유하면 기기 안의 OCR이 글자를 읽고(무료, 네트워크 없음) 곧바로 Duo에 넣어 줘요. **Poly Quiet** — 검토와 같은 파이프라인이지만 알림도, 최종 화면도 없어요: 결과는 클립보드와 저널로만 가요(백그라운드에서 빨리 돌릴 때). **Poly Compress**(Apple Intelligence 기기 전용: iPhone 15 Pro 이상, 16/16e/17 전 라인업) — 긴 글을 선택 → 공유 → Compress: Apple의 무료 기기 내 모델이 글을 줄여 주고 Duo를 자동으로 실행해요(긴 글의 시간 초과를 막아 줘요).

모드를 고르면 곧바로 **상태 알림**이 와요(«무슨 일이 일어나는지, 얼마나 기다리는지»). 그다음 답이 화면과 클립보드에 나타나기까지 대략 1–2분이에요. 흔한 작업 20가지 이상에 쓸 수 있는 문구는 `recipes.md`에 있어요. 최종 답은 항상 한 줄 요지로 시작하고 «확신도: 높음/중간/낮음»으로 끝나요. **단축어가 실행되는 동안에는 휴대폰을 그대로 두세요** — 화면을 만지면 취소돼요(조용히 멈춘 것 같으면 그냥 다시 실행하세요). 예외는 **❓ 되묻기**예요: 일부러 두 번째 창을 열어 추가 질문에 답하게 해요(또는 «건너뛰기» 탭) — 오류가 아니라 흐름의 일부예요. 답하면 단축어가 알아서 이어 가요.

## 이런 점이 좋아요

- **어떤 앱에서든:** 텍스트 선택 → 공유 → Duo — 질문 상자에 텍스트가 이미 들어 있어요. «번역해 줘/확인해 줘/설명해 줘»를 덧붙여 실행하세요.
- **저널:** 실행할 때마다 `Duo-journal.md`에 기록돼요(파일 → iCloud Drive → Shortcuts). 질문과 판정의 전체 기록이 한곳에 있어요. 처음 실행할 때 파일 접근을 **항상 허용**으로 허락하세요.
- **손 안 대고 실행:** 설정 → 동작 버튼 → «단축어 실행» → Duo. 또는 휴대폰 뒷면 두 번 탭: 설정 → 손쉬운 사용 → 터치 → 뒷면 탭 → Duo. 음성으로는 «Hey Siri, Duo.»
- **진입 방법 더 보기:** 홈 화면이나 잠금 화면의 위젯(홈 화면을 길게 누르기 → + → 단축어 → Duo), 제어 센터(설정 → 제어 센터 → «단축어» 추가), 책상이나 차에 두는 NFC 태그(단축어 → 자동화 → NFC → Duo 실행).
- **사진을 듀오에게:** 주된 방법은 **Poly Photo** 동반 단축어예요(사진/PDF 공유 → OCR → Duo를 대신 실행). 사진의 글자가 아니라 이미지를 *시각적으로* 읽고 싶다면 Claude의 카메라 위젯 → 분석 → 복사 → 텍스트를 Duo에 공유하세요.
- **내 글 확인하기:** 어디서든 초안을 선택 → 공유 → Duo → **🩺 조언자** 모드 — 고쳐 쓰지 않고 검토해요(공동 저자가 되지도 않아요).
- **iPhone 15 Pro 이상:** 단축어에는 Duo를 확장할 수 있는 «모델 사용» 동작(Apple Intelligence, 무료, 인터넷 불필요)이 있어요 — 예를 들면 모드 자동 선택. iPhone 14 이하에서는 이 동작이 없지만 Duo는 없어도 잘 돌아가요.
- **바로 듣기 시작(선택 사항):** 단축어 편집기에서 첫 «묻기» 동작을 펼치고 «즉시 받아쓰기» 토글을 켜세요 — 그러면 아이콘을 탭하자마자 질문을 듣기 시작해요. 입력과 공유 시트에는 꺼 두는 것이 더 편하기 때문에 기본값은 꺼짐이에요.

## Trio — 세 번째 목소리 (무료 키)

`Trio.shortcut`은 듀오에 세 번째 AI를 더해요. 질문과 ChatGPT의 답, Claude의 최종 답을 읽고 둘 다 놓친 것만 짚어 줘요.

**키 없이(iPhone 15 Pro 이상, iOS 26+):** 세 번째 목소리가 Apple Intelligence 자체라서 키도 가입도 필요 없어요. 내 iPhone이 해당하는지 모르겠나요? 설정 → 일반 → 정보 → 모델 이름. 키 없는 Trio는 [한국어](https://www.icloud.com/shortcuts/99366127269947f285147e66af8109b9) · [English](https://www.icloud.com/shortcuts/2a24e0157e4a445bae92ed1410907b9f) · [Español](https://www.icloud.com/shortcuts/281f56b82f7444438220fdffcbb46f22) · [Português](https://www.icloud.com/shortcuts/4000dcb2b9d64dcfaa44062c92e51b69) 판으로 설치할 수 있어요.

**오래된 iPhone이거나 키를 쓰고 싶다면:** Trio가 AI 회사에서 받는 긴 비밀번호인 무료 키를 한 번 물어봐요(1분, 카드 없음). 무료 키 하나 — 또는 여러 개 — 로 이 순서대로 돌아가요.
- **console.groq.com/keys** → Create API Key(`gsk_`로 시작해요, 문자 인증 없음, Google 계정으로 로그인);
- **aistudio.google.com/apikey** → Create API key(Gemini, `AIza`로 시작해요, 문자 인증 없음);
- **build.nvidia.com/settings/api-keys** → Generate API Key(가장 강력해요, 문자 인증 코드를 요구해요, `nvapi-`로 시작해요);
- **openrouter.ai/keys** → Create key(여러 회사의 무료 모델 수십 개, `sk-or-`로 시작해요).

키 하나면 충분하고, 키가 많을수록 Trio가 조용해질 일은 거의 없어요. 직접 쓰는 유료 키(`xai-`, `sk-ant-`, `sk-`)도 쓸 수 있어요.

Trio를 실행하고 물어보면 키를 붙여 넣으세요 — 여러 개라면 한 줄에 하나씩. 키는 단축어 안이 아니라 iCloud Drive → Shortcuts → `poly-key.txt`에 저장돼요. 처음 실행할 때 iPhone이 권한을 4–6번 물어봐요 — 매번 바로 **항상 허용**을 탭하세요(답하지 않은 요청은 닫히고, 그러면 단축어가 접근할 수 없다고 말해요).

Trio는 답이 올 때까지 모든 키로 모든 무료 모델을 차례로 시도해요. 과부하이거나 하루 한도를 다 쓴 모델은 다음 모델로 넘어가고, 잔액이 없는 키나 유효하지 않은 키는 건너뛰어요. 전부 실패할 때에만 각각이 무엇이라고 답했는지(잔액 없음, 한도, 과부하, 유효하지 않은 키)와 해야 할 일을 보여 줘요. 나중에 키를 추가하려면 `poly-key.txt`(파일 → iCloud Drive → Shortcuts)의 새 줄에 붙여 넣거나, 파일을 지우고 Trio를 다시 실행하세요.

## iCloud에 대해 — 유료 플랜은 필요 없어요

Duo는 유료 iCloud가 필요 없어요. 핵심 흐름(질문 → 두 AI → 화면과 클립보드의 답)은 iCloud를 전혀 건드리지 않아요. iCloud를 쓰는 것은 선택 사항인 두 가지 편의 기능, 실행 저널과 이미지 파일뿐이고, 둘 다 킬로바이트 단위라서 모든 Apple ID에 있는 무료 5GB로 수십 년을 쓸 수 있어요. iCloud Drive가 꺼져 있거나 가득 차도 답은 여전히 화면과 클립보드에 도착해요(설계상 보장돼요) — 저널 기록만 건너뛰어요. 저널이 아예 필요 없나요? 아래 개인정보 보호를 보세요.

## 개인정보 보호

`Duo-journal.md`는 모든 질문과 답을 iCloud Drive에 일반 텍스트로 저장해요. 기록을 남기고 싶지 않다면 단축어 편집기에서 저널 동작을 삭제하세요. 이미 있는 내용을 지우려면 파일 앱에서 `Duo-journal.md` 파일을 삭제하세요. 저널이 너무 커지면 파일 이름을 바꾸기만 하세요(예: `Duo-journal-august.md`) — 다음 실행 때 새 파일이 자동으로 만들어져요.

**내 파일이 공개된 그 파일일까요?** `releases/SHA256SUMS`에는 이 저장소 `releases/` 폴더에 있는 모든 Duo와 Trio 파일의 해시가 적혀 있어요. 거기서 내려받은 파일과는 일치하지만 iCloud 링크로 추가한 파일과는 일치하지 않아요(Apple이 공유할 때 다시 서명하기 때문이에요). 파일을 파일 앱에 저장한 다음, Mac에서 그 폴더에서 `shasum -a 256 Duo.shortcut`을 실행해 내 언어의 줄과 비교하세요. (서명은 재현되지 않아요. 직접 다시 빌드한 파일은 달라지고, 내려받은 파일만 일치해요.) 파일이 하는 일은 `tools/verify.py`가 확인해요. 서명된 파일을 풀어서 `locales/`의 공개 텍스트와 비교해요.

## 문제가 생겼다면

**작동하지 않을 때 — 빠른 해결:**
- **동작 목록에 «Ask Claude»가 없어요:** Claude 앱과 iOS를 업데이트하세요(iOS 18 이상).
- **빈 답:** ChatGPT 앱과 Claude 앱을 한 번씩 열었다가 다시 실행하세요.
- **ChatGPT가 «logged out»이라고 해요:** ChatGPT를 열었다가 닫고, 단축어를 다시 실행하세요.
- **탭하기 전에 권한 요청이 사라졌어요:** 그냥 다시 실행하고 바로 **항상 허용**을 탭하세요.


- **ChatGPT가 «You are logged out»이라고 해요**(분명히 로그인되어 있는데도) — ChatGPT 앱을 열었다가 닫고 Duo를 다시 실행하세요. 알려진 오류이고 항상 이렇게 해결돼요.
- **Claude가 «This model isn't available right now»라고 해요** — 무료 일일 한도에 도달했거나, Claude 앱에서 고른 모델이 내 플랜에 없는 거예요. Claude 앱에서 Sonnet을 고르거나 한도가 초기화될 때까지 기다리세요. 그동안 Trio는 키로 쓰는 무료 AI로 확인해요.
- **Claude가 조용해요 / 긴 질문에 빈 답이 와요** — Claude 동작에는 시간 제한이 있어서, Claude가 끝내기 전에 제어를 돌려줄 수 있고, 그동안 Claude는 자기 앱 안에서 답을 계속 쓰고 있어요. Claude를 열면 답이 거기 있어요 — 앱의 복사 버튼으로 복사하세요. 다음에는 질문을 더 짧게 하면 더 안정적으로 돌아와요. 아예 실패했다면 최근 사용 항목에서 단축어를 위로 밀어 종료하고 다시 실행하세요.
- **Duo를 다른 사람에게 공유하기:** `Duo.shortcut`을 압축하지 말고 파일 그대로 보내세요(휴대폰에서 zip은 단계가 늘어나요). Telegram에서는 파일을 길게 누르고 → 공유/파일에 저장을 고르세요. 한 번 탭하면 안 돼요.
- **Duo 단축어의 이름을 바꾸지 마세요.** Photo와 Compress 동반 단축어, 그리고 «🔁 다른 모드» 버튼은 모두 정확히 «Duo»라는 이름으로 불러요. 이름을 바꾸거나(다시 가져와서 «Duo 1»이 되거나) 하면 그 세 경로가 조용히 작동하지 않아요. 다시 설치하다가 중복이 생기면 옛 단축어를 삭제하고 «Duo»라는 이름 하나만 남기세요.
- **답이 기대보다 약해요** — 동작은 Claude 앱에서 기본으로 설정된 모델을 써요: Claude를 열어 모델을 바꾸고, 닫은 뒤 Duo를 다시 실행하세요. 좋은 습관: 중요한 실행 전에 Claude 상단에서 모델을 확인하세요.
- **링크만 공유했더니 아무 일도 없었어요** — 동작은 웹 페이지를 직접 가져오지 않아요: 페이지를 열어 텍스트 일부를 선택하고 그 텍스트를 공유하세요.
- **덤:** 최종 답은 공유 클립보드(유니버설 클립보드)에도 들어가요 — Mac이나 iPad에서 휴대폰을 만지지 않고 Cmd+V로 붙여 넣을 수 있어요.
- **iOS 대규모 업데이트 후**(예를 들어 iOS 27) 검토를 한 번 시험 삼아 실행하세요. 단축어 대규모 업데이트는 권한을 다시 물어보거나 «완료» 카드를 하나 더 보여 줄 수 있어요 — 한 번 실행하면 드러나고 해결돼요.
- 메시지 비용은 각 서비스의 **구독**에서 나가요(API가 아니에요). 평소 채팅과 같은 한도를 공유해요. 쓰이는 모델은 각 앱에서 기본으로 설정된 모델이에요.

## 최종 답 다음에는

최종 화면 아래에서 Duo가 물어봐요: **«✅ 완료»** 또는 **«🔁 다른 모드 — 같은 질문»**. 두 번째를 고르면 질문이 이미 채워진 채로(수정할 수 있어요) Duo가 다시 시작하고 다른 모드를 고를 수 있어요. 검토를 돌린 뒤 같은 질문을 다시 입력하지 않고 곧바로 쟁점 지도를 돌릴 때 편해요.
