# Duo 활용법 — 무엇을 물어볼지, 어떤 모드를 쓸지

C1M Duo(Duo)는 만능 도구예요. 어떤 작업이든 알맞은 문구와 알맞은 모드의 조합이에요. 아래는 시험해 본 활용 목록이에요. 이미 있는 글에 가장 빠른 방법: **텍스트 선택 → 공유 → Duo** — 질문 상자에 곧바로 들어가니 앞에 지시만 덧붙이면 돼요.

| 작업 | 질문에 쓸 내용 | 모드 |
|---|---|---|
| 보내기 전에 이메일 교정 | "이 이메일을 확인하고 따뜻하고 전문적인 어조를 유지하며 개선해 줘: [텍스트]" | ⚖️ 검토 · 3✉ (이미 완성되어 고치면 안 되나요? 대신 🩺 조언자를 쓰세요 — 아래 참고) |
| 어렵거나 불쾌한 메시지에 답하기 | "받은 메시지야. 어조와 의도를 분석하고, 서로 다른 어조로 답장 3개를 제안해 줘: [텍스트]" | ⚖️ 검토 · 3✉ |
| 코드를 쓰고 검토받기 | "[필요한 것]을 써 줘. 요구 사항: …" | ⚖️ 검토 · 3✉ (🥊 논쟁 · 4✉은 허점을 찾는 사람이 특히 필요한, 중요한 코드에만) |
| 기존 코드 검토 | "버그, 위험, 개선할 점을 찾아 줘: [코드]" | 👀 나란히 보기 · 2✉ |
| 결정하기 (살까 / 바꿀까 / 시작할까?) | "[아이디어/결정]을 해야 할까? 상황: …" | ⚔️ 결정 · 3✉ |
| 프로젝트나 거래의 위험 평가 | "[대상]의 위험은 무엇이고 어떻게 막을 수 있어?" | ⚔️ 결정 · 3✉ |
| 글이나 뉴스 기사 사실 확인 | "이 주장들에 사실 오류가 있는지 확인해 줘: [텍스트]" | 🔀 종합 · 3✉ |
| 중요한 질문 (의료 / 법률 / 금융) | 그대로 질문하세요 | 🔀 종합 · 3✉ (🥊 논쟁은 대체재가 아니에요 — 결론을 시험해 보고 싶을 때 쓰는 모드예요) |
| 새로운 주제를 빠르게 이해하기 | "[주제]를 비전문가가 알 수 있게 군더더기 없이 설명해 줘" | ⚖️ 검토 · 3✉ |
| 스스로 점검하며 배우기 | "[주제]를 설명하고 정답과 함께 스스로 점검할 질문 3개를 줘" | ⚖️ 검토 · 3✉ |
| 회의나 협상 준비 | "[누구]와 [주제]로 회의가 있어. 어떤 질문을 하고 어떤 반론을 예상해야 하는지, 답변과 함께 알려 줘" | ⚔️ 결정 · 3✉ |
| 이름, 슬로건, 창의적인 안 | "[대상]의 다양한 스타일 변형 10개를 주고, 이유와 함께 상위 3개를 골라 줘" | 👀 나란히 보기 · 2✉ |
| 기사 요약 | 기사를 선택 → 공유 → "요약해 줘: 핵심 요점과 결론" | ⚖️ 검토 · 3✉ |
| 하루 계획 / 할 일 우선순위 | "내 할 일이야: […]. 우선순위를 매기고 순서를 제안해 줘" | ⚔️ 결정 · 3✉ |
| 번역하고 다듬기 | "[언어]로 번역하고 문체를 다듬어 줘: [텍스트]" | ⚖️ 검토 · 3✉ |
| 브레인스토밍 | "이 문제에 대한 뻔하지 않은 해결책 5개를 제안하고, 어느 것이 현실적인지 평가해 줘: […]" | ⚖️ 검토 · 3✉ (이것은 «만들고 거르기»이지 «시험해 보기»가 아니에요 — 논쟁은 필요 없어요) |
| 긴 설명 → 짧은 요약 | "[…]을 자세히 설명한 다음, 끝에 한 문장짜리 요점 3개로 압축해 줘" | ⚖️ 검토 · 3✉ |
| 난감한 메시지 → 답장 초안 | 대화를 선택 → 공유 → "어조를 분석하고 답장을 제안해 줘" | ⚔️ 결정 · 3✉ |
| 내 글을 고쳐 쓰지 않고 확인 | 초안을 선택 → 공유 → (아무것도 덧붙이지 마세요) | 🩺 조언자 · 1✉ |
| 논쟁적인 주제 — 실제로 무엇이 사실일까? | 그대로 질문하세요 — 결론을 억지로 내지 않고 일치와 불일치의 지도를 받아요 | 🗺 쟁점 지도 · 3✉ |
| 막연한 질문, 무엇을 원하는지 잘 모르겠을 때 | 그대로 질문하세요 — 먼저 추가 질문을 받아요 | ❓ 되묻기 · 2✉ |
| 로고, 도표, 카드, 일러스트 | "[무엇을, 어떤 스타일로] 그려 줘" — 고를 수 있는 벡터 스케치 두 장 | 🎨 그림 · 2–3✉ |
| 문서, 표지판, 메뉴 사진 | 사진을 공유 → Poly Photo (OCR이 나머지를 처리해요) | Poly Photo 동반 단축어 |
| 작은 화면 / 이동 중 | 음성으로 질문하세요 — 답을 소리 내어 읽어 주고 텍스트는 클립보드에 들어가요 | Poly Voice 동반 단축어 |
| 어떤 모드를 고를지 모를 때 | 그대로 질문하세요 — 모드는 직접 고르지 마세요 | 🧭 자동 · +1✉ (ChatGPT가 하나 추천하고, Duo가 같은 질문으로 다시 시작해요) |
| 메시지 예산은 빠듯한데 두 가지 견해는 원할 때 | 그대로 질문하세요 | ➕ 보탬 · 2✉ (🔀 종합의 더 저렴한 대안: Claude의 기준 + ChatGPT의 개선점 목록 — 3개 대신 메시지 2개) |

## 기법 메모

- **논쟁은 기본값이 아니라 드물게 쓰는 도구예요.** 결론을 깨뜨려 보려는 사람이 특히 필요할 때 아껴 두세요: 중요한 코드, 실수하면 비싼 결정. 일상적인 글쓰기는 검토나 조언자로, 중요한 질문은 종합으로 처리하세요.
- **AI들이 서로 보기 전에 먼저 답하는 이유.** 답을 읽은 검토자는 혼자였다면 내지 않았을 답에도 동의하기 쉬워요. 그래서 ⚖️ 검토, 👀 나란히 보기, 🔀 종합, 토론에서는 각 AI가 먼저 혼자 답하고, 그다음에야 두 답을 비교해요. 이렇게 두 답이 일치하면, 읽고 나서 동의한 것보다 무게가 더 커요. ➕ 보탬과 ✍️ Claude가 쓰고 ChatGPT가 확인은 고쳐 쓰고 보태는 용도이고, 사실 확인용이 아니에요.
- 질문 상자 키보드의 **마이크 키**를 누르면 설정 없이 음성 입력을 쓸 수 있어요.
- 질문 끝의 **수식어**도 통해요: «간결하게 답해 줘», «자세히», «글머리 기호로만» — 모델이 따라요.
- 자주 쓰는 활용에는 **작은 전용 단축어**를 만들 수 있어요: 작업이 미리 적힌 텍스트 블록 다음에 Duo를 가리키는 «단축어 실행»을 두세요(작업이 미리 채워진 질문이 돼요).
- 실행 결과는 이미 **클립보드**에 있어요 — 이메일이나 채팅에 바로 붙여 넣으세요 — 그리고 **저널** `Duo-journal.md`에도 저장돼요.
