# C1M Duo의 과학적 근거

Duo는 NeurIPS 2026 워크숍에 채택된 두 편의 논문과, 우리 동반 연구 데이터의 재분석에 바탕을 둡니다. (1) 자기 확신은 약한 신호입니다 (TAE 워크숍, doi:10.5281/zenodo.23197651): 16개 모델로 이루어진 블라인드 컬렉션(2026년 7월 말)의 API 모델 9개(claude-haiku-4-5, gpt-5-mini, gemini-3.6-flash, grok-4-fast, deepseek-chat, qwen-plus, kimi-k3, glm-4.5, mistral-small-latest)에서, 모델이 밝힌 확신도가 자기 답의 정답 여부를 예측하는 AUROC는 0.53–0.79입니다. 사전에 지정한 주 패널(CN: DeepSeek, Alibaba, Moonshot)에서는 블라인드로 물은 모델들과의 일치가 자기 확신의 0.55에 비해 0.83에 이릅니다 (Δ +0.29; 정오 라벨 없이 다시 코딩하면 0.775 대 0.545). (2) 검증은 먼저 블라인드여야 합니다 (Who Verifies the Agents? 워크숍, doi:10.5281/zenodo.23197641): 2026년 7월의 API 검증 모델 6개(Anthropic, OpenAI, Google, DeepSeek, Alibaba, Moonshot)를 쓴 탐색적 동조 실험군에서, 블라인드로는 반대했던 검증 모델이 같은 답을 동료의 답으로 보게 되자 38.5%의 경우에 찬성했습니다 (168/436). Duo는 두 답을 비교하기 전에 블라인드로 먼저 받습니다 — 검토, 종합, 나란히 보기 모두에서 그렇습니다. 같은 논문에서, 전체 모집단 기준 난이도로 가장 어려운 5분위에서 2026년 7월 API 패널(연구소별 모델 1개; 논문에서는 "frontier"라 불렀지만 9개 중 8개는 저가/중급 모델)은 106개 질문에 걸쳐 342개의 답을 반복했고, 원래 채점으로는 맞은 것이 하나도 없었습니다. (3) 동반 연구가 공개한 플래그십 세대 데이터의 사후 재분석 (2026년 10월 26일) (doi:10.5281/zenodo.22166995; 연구소별 플래그십 1개, 2026년 8월 5일 시점): gpt-5.6-sol + claude-fable-5 쌍, SimpleQA 1,459문항, 블라인드 답변이며, GPT의 답은 결정적 동치로 일치할 때만 내보냅니다 — 커버리지 69.6%, 내보낸 답의 정답률 98.1% (985/1,004) [97.2, 98.9], GPT 단독은 95.3%. 자신 있게 틀린 비율(conf ≥ 80, 자신 있는 답 중)은 GPT 4.6% → 1.9%, Claude 10.3% → 2.8%이며, 두 플래그십이 같은 자신 있는 오답을 낸 것은 100문항 중 1문항(1.0%)뿐입니다. WVA의 106문항(7월 모델에게는 어려운 문제)에서 플래그십 쌍은 37문항에서 일치했고 34문항을 맞혔습니다. 같은 연구소들의 중급 쌍(gpt-5-mini + claude-haiku-4-5, 2026년 7월): 커버리지 8.6%, 내보낸 답의 정답률 36.6%, 106문항에서는 0/13. 더 강한 쌍은 모든 실용적 축에서 앞섭니다: 커버리지 ×8, 내보낸 답의 정확도 37% → 98%, 내보낸 답 중 함께 자신 있게 틀린 비율 8% → 1.5%. ChatGPT Plus/Pro와 Claude Pro/Max에서는 Duo가 그 요금제가 제공하는 가장 강한 모델을 추가 비용 없이 돌립니다. 위의 수치는 2026년 8월 5일 쌍에 대한 것입니다.

한계: SimpleQA는 공개되어 있고, gpt-5.6-sol는 답의 61.6%에서 정답 문자열을 그대로 되풀이합니다. 106문항에서는 단독으로 95.2%를 맞히고 64.2%에서 정답을 되풀이합니다 — 7월 모델에게는 어려웠지만 이 모델에게는 그렇지 않습니다. 게이트가 걸러내는 GPT의 자신 있는 오답 비율은 중급 쌍의 게이트보다 작습니다 (70.8% 대 92.3%). 플래그십 대 중급은 측정점 두 개입니다 (달이 다르고, GPT의 추론 강도는 medium 대 minimal). 쌍의 수치는 블라인드 답을 나중에 비교하는 방식을 설명하며, Duo가 검토·종합·나란히 보기에서 쓰는 방식이지만, Duo의 어떤 모드나 현재 모델에 대해 측정된 정확도는 아닙니다. WVA의 0은 전체 모집단 난이도에서 유지됩니다. 패널 자신의 모델을 뺀 난이도(leave-panel-out)에서는 블록 교차 패널에서는 남지만(0/116) 합산에서는 남지 않습니다(78/354). WVA의 수동 정답 판정에서 찾은 타당한 답을 정답으로 인정하면 그 0은 최대 13/342가 됩니다 (리프트 0.98×). 동조 실험군의 역프롬프트 대조는 로컬 모델 6개로 수행했습니다. TAE의 US 패널에서는 합산한 자기 확신이 앞서는데(0.84 대 0.70), 이는 모델 간 효과입니다 (순위 정규화 후 0.67). Claude는 앱의 기본 모델로 실행되고, ChatGPT는 `model: auto`로 실행되며 유료 요금제에서는 그 요금제의 모델이 선택됩니다. 현재의 플래그십은 아직 측정되지 않았습니다. 데이터와 논문: github.com/vadimchernets/papers · polyhelper.ai/research
