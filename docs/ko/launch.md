# 아무것도 열지 않고 C1M Duo에게 물어보기

Duo는 단축어라서 iPhone이 거의 어디서든 시작할 수 있어요. 아래에서 한두 가지를 고르세요. 각각 설정에 1분도 걸리지 않고, 한 번만 하면 돼요.

**어디서나 통하는 팁:** 확인할 텍스트를 먼저 복사하세요. 아무것도 공유하지 않고 Duo를 시작하면, 복사해 둔 내용이 이미 들어 있는 질문 상자가 떠요.

| 어디서 | 설정 방법 | 작동하는 기기 |
|---|---|---|
| **«Hey Siri, Duo»** | 설정할 것이 없어요. Siri가 이름으로 단축어를 알아요. «Duo»라는 이름을 유지하세요. | 모든 iPhone, iOS 18+ |
| **공유 버튼** | 아무 앱에서 텍스트 선택 → 공유 → **Duo**. 이미 켜져 있어요. | 모든 iPhone, iOS 18+ |
| **휴대폰 뒷면 두 번 탭** | 설정 → 손쉬운 사용 → 터치 → **뒷면 탭** → 두 번 탭 → **Duo**. | iPhone 8 이상 |
| **제어 센터** | 제어 센터 열기 → **+**(왼쪽 위) → 제어 항목 추가 → **단축어** → **Duo** 선택. | iOS 18+ |
| **잠금 화면 버튼** | 잠금 화면을 길게 누르기 → 사용자화 → 잠금 화면 → 아래쪽 버튼 탭 → **단축어** → **Duo**. | iOS 18+ |
| **동작 버튼** | 설정 → **동작 버튼** → **단축어**로 넘기기 → **Duo**. | iPhone 15 Pro 이상 |
| **홈 화면 아이콘** | 단축어 앱 → **Duo**를 길게 누르기 → 공유 → **홈 화면에 추가**. | 모든 iPhone |
| **Mac이나 iPad** | 최종 답은 공유 클립보드에도 있어요: Mac에서 Cmd+V를 누르세요. | 같은 Apple ID, Handoff 켜기 |

## 스크린샷을 두 AI로 확인하기

스크린샷을 찍고, 미리보기를 탭하고, 텍스트를 길게 누르세요(실시간 텍스트) → **전체 선택** → 공유 → **Duo**. iOS 18인 모든 iPhone에서 돼요.

iOS 27은 스크린샷을 찍을 때 단축어를 스스로 시작할 수도 있어요: 단축어 앱 → **자동화** → **+** → **스크린샷** → **단축어 실행** → **Duo**. 아직 휴대폰에서 시험해 보지 않았어요.
