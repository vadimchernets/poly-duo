# कुछ भी खोले बिना C1M Duo से पूछिए

Duo एक शॉर्टकट है, इसलिए iPhone उसे लगभग कहीं से भी शुरू कर सकता है। इनमें से एक या दो चुन लीजिए। हर एक को सेट करने में एक मिनट से कम लगता है, और यह एक ही बार करना होता है।

**एक सुझाव जो हर जगह चलता है:** जिस टेक्स्ट को जँचवाना है, उसे पहले कॉपी कर लीजिए। अगर आप कुछ शेयर किए बिना Duo शुरू करते हैं, तो सवाल का ख़ाना उसी कॉपी किए टेक्स्ट के साथ खुलता है।

| कहाँ से | कैसे सेट करें | कहाँ चलता है |
|---|---|---|
| **«Hey Siri, Duo»** | कुछ सेट नहीं करना: Siri शॉर्टकट को उसके नाम से पहचानती है। नाम «Duo» ही रखिए। | कोई भी iPhone, iOS 18+ |
| **शेयर बटन** | किसी भी ऐप में टेक्स्ट चुनिए → शेयर → **Duo**। यह पहले से चालू है। | कोई भी iPhone, iOS 18+ |
| **फ़ोन के पीछे दो बार टैप** | सेटिंग्स → एक्सेसिबिलिटी → टच → **बैक टैप** → दो बार टैप → **Duo**। | iPhone 8 और नए |
| **कंट्रोल सेंटर** | कंट्रोल सेंटर खोलिए → **+** (ऊपर बाईं ओर) → कंट्रोल जोड़ें → **शॉर्टकट** → **Duo** चुनिए। | iOS 18+ |
| **लॉक स्क्रीन का बटन** | लॉक स्क्रीन को देर तक दबाइए → कस्टमाइज़ → लॉक स्क्रीन → नीचे का कोई बटन टैप कीजिए → **शॉर्टकट** → **Duo**। | iOS 18+ |
| **ऐक्शन बटन** | सेटिंग्स → **ऐक्शन बटन** → **शॉर्टकट** तक स्वाइप कीजिए → **Duo**। | iPhone 15 Pro और नए |
| **होम स्क्रीन का आइकन** | शॉर्टकट ऐप → **Duo** को देर तक दबाइए → शेयर → **होम स्क्रीन में जोड़ें**। | कोई भी iPhone |
| **Mac या iPad** | अंतिम जवाब साझा क्लिपबोर्ड में भी रहता है: अपने Mac पर Cmd+V दबाइए। | वही Apple ID, Handoff चालू |

## स्क्रीनशॉट को दो AI से जँचवाइए

स्क्रीनशॉट लीजिए, उसके प्रीव्यू पर टैप कीजिए, टेक्स्ट को देर तक दबाइए (Live Text) → **सब चुनें** → शेयर → **Duo**। iOS 18 वाले किसी भी iPhone पर चलता है।

iOS 27 स्क्रीनशॉट लेते ही शॉर्टकट अपने-आप भी शुरू कर सकता है: शॉर्टकट ऐप → **ऑटोमेशन** → **+** → **स्क्रीनशॉट** → **शॉर्टकट चलाएँ** → **Duo**। इसे अभी तक किसी फ़ोन पर आज़माया नहीं गया है।
