# Duo 食谱 —— 问什么，用哪个模式

C1M Duo 是个通才：任何任务都归结为对的说法加上对的模式。下面是一份经过实践的食谱库。处理现成文字最快的路径：**选中文字 → 共享 → Duo** —— 它会直接落进问题框，你只要在前面补上指令。

| 任务 | 问题里写什么 | 模式 |
|---|---|---|
| 发送前校对一封邮件 | “检查并改进这封邮件，保持温和的专业语气：[文字]” | ⚖️ 审校 · 3✉（已经是定稿、不该被改写？那就用 🩺 顾问 —— 见下文） |
| 回复一条难办或让人不舒服的消息 | “这是我收到的一条消息。分析它的语气和意图，并给出 3 种不同语气的回复：[文字]” | ⚖️ 审校 · 3✉ |
| 写代码并让人复核 | “写一个[你要的东西]。要求：……” | ⚖️ 审校 · 3✉（🥊 辩论 · 4✉ 只留给关键代码，也就是你确实想让人专门去找漏洞的时候） |
| 复核现有代码 | “找出 bug、风险，以及可以改进的地方：[代码]” | 👀 并排对照 · 2✉ |
| 做一个决定（买 / 换 / 上线？） | “我该不该[想法/决定]？背景：……” | ⚔️ 决策 · 3✉ |
| 评估一个项目或一笔交易里的风险 | “[这件事]里有哪些风险，我该怎么把它们堵上？” | ⚔️ 决策 · 3✉ |
| 核查一段文字或一则新闻的事实 | “检查这些说法里有没有事实错误：[文字]” | 🔀 综合 · 3✉ |
| 赌注很大的问题（医疗 / 法律 / 财务） | 原样问出来 | 🔀 综合 · 3✉（🥊 辩论 不是它的替代品 —— 辩论是你确实想让结论经受压力测试的时候用的） |
| 快速搞懂一个新话题 | “讲给外行听，别灌水：[话题]” | ⚖️ 审校 · 3✉ |
| 学点东西并自我检测 | “讲讲[话题]，再给我 3 道带答案的自测题” | ⚖️ 审校 · 3✉ |
| 为一场会议或谈判做准备 | “要和[谁]开一个关于[话题]的会。我该问哪些问题，又该预料到哪些反对意见，请附上应对答案？” | ⚔️ 决策 · 3✉ |
| 起名、标语、创意选项 | “给我[这个东西]的 10 个不同风格的版本，然后挑出你心中的前 3 名并说明理由” | 👀 并排对照 · 2✉ |
| 总结一篇文章 | 选中文章 → 共享 → “总结一下：要点和结论” | ⚖️ 审校 · 3✉ |
| 规划一天 / 给任务排优先级 | “这是我的任务清单：[……]。给它们排出优先级，并建议一个顺序” | ⚔️ 决策 · 3✉ |
| 翻译并润色 | “翻译成[语言]并润色文风：[文字]” | ⚖️ 审校 · 3✉ |
| 头脑风暴 | “针对这个问题给出 5 个不那么显而易见的解法：[……]，然后评估哪些是现实可行的” | ⚖️ 审校 · 3✉（这是“生成再筛选”，不是“压力测试”—— 用不着辩论） |
| 长篇解释 → 简短总结 | “详细讲讲[……]，然后在最后压缩成 3 条一句话要点” | ⚖️ 审校 · 3✉ |
| 难堪的消息 → 回复草稿 | 选中对话 → 共享 → “分析语气，并给出一个回复” | ⚔️ 决策 · 3✉ |
| 检查你自己写的东西，但不要改写 | 选中你的草稿 → 共享 →（什么都别加） | 🩺 顾问 · 1✉ |
| 有争议的话题 —— 到底什么才是真的？ | 原样问出来 —— 你会拿到一张共识与分歧的地图，不带强行结论 | 🗺 分歧地图 · 3✉ |
| 问题很含糊，你自己也说不清想要什么 | 原样问出来 —— 系统会先反过来问你几个问题 | ❓ 追问 · 2✉ |
| 标志、示意图、贺卡、插画 | “画[什么，什么风格]”—— 两张矢量草图任你挑 | 🎨 绘图 · 2–3✉ |
| 一份文件、路牌或菜单的照片 | 共享这张照片 → Poly Photo（剩下的交给 OCR） | Poly Photo 搭档 |
| 屏幕小 / 在路上 | 用语音问 —— 答案会念给你听，文字则落进剪贴板 | Poly Voice 搭档 |
| 不确定该挑哪个模式 | 原样问出来 —— 别自己选模式 | 🧭 自动 · +1✉（ChatGPT 推荐一个；Duo 会带着同一个问题重新开始） |
| 消息额度紧张，但仍然想要两种看法 | 原样问出来 | ➕ 增补 · 2✉（🔀 综合 的便宜替代：Claude 的主干 + ChatGPT 的改进清单 —— 2 条消息而不是 3 条） |

## 技巧札记

- **辩论是件不常用的工具，不是默认选项。** 把它留给那些你确实需要有人去把结论拆开的场合：关键代码，出错代价高昂的决定。日常写作走审校或顾问；赌注大的问题走综合。
- **想要答案尽量靠谱时，先让两边各自作答。** 在 ⚖️ 审校 里，Claude 是先读了 ChatGPT 的答案再去检查它，而看过答案的检查者往往倾向于认同它，所以那里的“两边一致”没有看上去那么有分量。在 👀 并排对照 和 🔀 综合 里，两个 AI 在看到对方之前各自作答，所以它们一致时，这个一致更有说服力。
- 问题框里键盘上的**麦克风键**让你零配置地用语音输入。
- 在问题末尾加上**修饰语**是有效的：“回答简洁一点”“详细一点”“只用要点列出”—— 模型会照做。
- 对于你经常用的某个食谱，可以做一条**专用的小快捷指令**：一段已经写好任务的文本，后面接一个指向 Duo 的“运行快捷指令”（这段任务就成了预先填好的问题）。
- 每次运行的结果已经在你的**剪贴板**里了 —— 直接粘进邮件或聊天 —— 而且它也保存在**日志** `Duo-journal.md` 里。
