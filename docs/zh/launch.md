# 不用打开任何东西，就能问 C1M Duo

Duo 是一条快捷指令，所以 iPhone 几乎可以从任何地方启动它。挑一两种方式就行，每种不到一分钟就能设好，而且只用设一次。

**到处都管用的小技巧：** 先把想让它检查的文字复制下来。如果你不分享任何内容就启动 Duo，弹出的提问框里会自动带着你刚复制的文字。

| 从哪里启动 | 怎么设置 | 适用于 |
|---|---|---|
| **“嘿 Siri，Duo”** | 不用设置：Siri 认得这条快捷指令的名字。请保持名字为“Duo”。 | 任何 iPhone，iOS 18+ |
| **共享按钮** | 在任意 App 里选中文字 → 共享 → **Duo**。已经是开着的。 | 任何 iPhone，iOS 18+ |
| **轻点两下手机背面** | 设置 → 辅助功能 → 触控 → **轻点背面** → 轻点两下 → **Duo**。 | iPhone 8 及更新机型 |
| **控制中心** | 打开控制中心 → **+**（左上角）→ 添加控制 → **快捷指令** → 选择 **Duo**。 | iOS 18+ |
| **锁定屏幕按钮** | 长按锁定屏幕 → 自定 → 锁定屏幕 → 点底部的一个按钮 → **快捷指令** → **Duo**。 | iOS 18+ |
| **操作按钮** | 设置 → **操作按钮** → 滑到 **快捷指令** → **Duo**。 | iPhone 15 Pro 及更新机型 |
| **主屏幕图标** | 快捷指令 App → 长按 **Duo** → 共享 → **添加到主屏幕**。 | 任何 iPhone |
| **Mac 或 iPad** | 最终答案同时在共享剪贴板里：在 Mac 上按 Cmd+V 即可。 | 同一个 Apple ID，已开启接力 |

## 让两个 AI 检查一张截图

截好图，点一下预览，长按其中的文字（实况文本）→ **全选** → 共享 → **Duo**。任何装了 iOS 18 的 iPhone 都能用。

iOS 27 还能在你截屏时自动启动快捷指令：快捷指令 App → **自动化** → **+** → **截屏** → **运行快捷指令** → **Duo**。这一项还没有在手机上试过。
