# Спросить C1M Duo, ничего не открывая

Duo — это команда, поэтому iPhone может запустить её почти откуда угодно. Выберите один-два способа. Каждый настраивается меньше чем за минуту, и делать это нужно один раз.

**Совет, который работает везде:** сначала скопируйте текст, который хотите проверить. Если запустить Duo, ничего не передавая, окно вопроса откроется с уже скопированным текстом.

| Откуда | Как настроить | Работает на |
|---|---|---|
| **«Привет, Siri, Duo»** | Настраивать нечего: Siri знает команду по имени. Оставьте имя «Duo». | любой iPhone, iOS 18+ |
| **Кнопка «Поделиться»** | Выделите текст в любом приложении → «Поделиться» → **Duo**. Уже включено. | любой iPhone, iOS 18+ |
| **Двойной тап по задней панели** | Настройки → Универсальный доступ → Касание → **Тап по задней панели** → Двойное касание → **Duo**. | iPhone 8 и новее |
| **Пункт управления** | Откройте Пункт управления → **+** (слева вверху) → Добавить элемент управления → **Быстрые команды** → выберите **Duo**. | iOS 18+ |
| **Кнопка на экране блокировки** | Долгое нажатие на экране блокировки → Настроить → Экран блокировки → тапните кнопку внизу → **Быстрая команда** → **Duo**. | iOS 18+ |
| **Кнопка действия** | Настройки → **Кнопка действия** → пролистайте до **Быстрая команда** → **Duo**. | iPhone 15 Pro и новее |
| **Иконка на экране «Домой»** | Приложение «Команды» → долгое нажатие на **Duo** → «Поделиться» → **На экран «Домой»**. | любой iPhone |
| **Mac или iPad** | Финальный ответ лежит и в общем буфере обмена: нажмите Cmd+V на Mac. | тот же Apple ID, Handoff включён |

## Проверить скриншот двумя ИИ

Сделайте скриншот, тапните по превью, удерживайте палец на тексте (Live Text) → **Выбрать все** → «Поделиться» → **Duo**. Работает на любом iPhone с iOS 18.

iOS 27 умеет и сама запускать команду при скриншоте: приложение «Команды» → **Автоматизация** → **+** → **Снимок экрана** → **Выполнить быструю команду** → **Duo**. На телефоне это пока не проверяли.
