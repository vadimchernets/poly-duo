# Рецепты Duo — что спрашивать и каким режимом

C1M Duo — универсал: любая задача = правильная формулировка вопроса + правильный режим. Ниже — проверенная библиотека рецептов. Самый быстрый путь для готового текста: **выделили текст → Поделиться → Duo** — текст сам встанет в окно вопроса, вам останется только дописать задание в начале.

| Задача | Как сформулировать | Режим |
|---|---|---|
| Проверка письма перед отправкой | «Проверь и улучши это письмо, сохрани тёплый профессиональный тон: [текст]» | ⚖️ Критика · 3✉ (письмо уже финальное и переписывать не нужно? Возьмите 🩺 Советник · 1✉ — см. ниже) |
| Ответ на сложное или неприятное сообщение | «Вот входящее сообщение. Разбери тон и намерения и предложи 3 варианта ответа в разных тонах: [текст]» | ⚖️ Критика · 3✉ |
| Код: написать и отревьюить | «Напиши [что нужно]. Требования: …» | ⚖️ Критика · 3✉ (🥊 Дебаты · 4✉ — только для критичного кода, когда специально нужен второй, кто ищет дыры) |
| Ревью готового кода | «Найди баги, риски и что улучшить: [код]» | 👀 Опрос · 2✉ |
| Принять решение (купить / поменять / запускать?) | «Стоит ли мне [идея/решение]? Контекст: …» | ⚔️ Решение · 3✉ |
| Оценка рисков проекта или сделки | «Какие риски у [затея] и как их закрыть?» | ⚔️ Решение · 3✉ |
| Проверка фактов в тексте или новости | «Проверь эти утверждения на фактические ошибки: [текст]» | 🔀 Синтез · 3✉ |
| Высокие ставки (медицина / юриспруденция / финансы) | Вопрос как есть | 🔀 Синтез · 3✉ (🥊 Дебаты — не замена, а отдельный случай: когда специально нужно, чтобы вывод ломали) |
| Быстро понять новую тему | «Объясни для неспециалиста, без воды: [тема]» | ⚖️ Критика · 3✉ |
| Обучение с самопроверкой | «Объясни [тему] и дай 3 вопроса для самопроверки с ответами» | ⚖️ Критика · 3✉ |
| Подготовка к встрече или переговорам | «Встреча про [тема] с [кто]. Какие вопросы задать и какие возражения ждать, с ответами?» | ⚔️ Решение · 3✉ |
| Названия, слоганы, креативные варианты | «Дай 10 вариантов [чего] в разных стилях, потом выбери топ-3 с обоснованием» | 👀 Опрос · 2✉ |
| Краткое содержание статьи | выделили статью → Поделиться → «Сделай выжимку: главные тезисы и вывод» | ⚖️ Критика · 3✉ |
| План дня / приоритизация задач | «Вот мои задачи: […]. Расставь приоритеты и предложи порядок» | ⚔️ Решение · 3✉ |
| Перевод с редактурой | «Переведи на [язык] и отшлифуй стиль: [текст]» | ⚖️ Критика · 3✉ |
| Мозговой штурм | «Предложи 5 неочевидных решений проблемы: […], а потом оцени, какие реалистичны» | ⚖️ Критика · 3✉ (тут «сгенерировать и отфильтровать», а не «сломать» — Дебаты не нужны) |
| Длинное объяснение → короткая выжимка | «Объясни подробно […], а в конце сожми в 3 пункта по одному предложению» | ⚖️ Критика · 3✉ |
| Неловкое сообщение → черновик ответа | выделили переписку → Поделиться → «Разбери тон и предложи ответ» | ⚔️ Решение · 3✉ |
| Проверить СВОЙ текст без переписывания | выделили свой черновик → Поделиться → (ничего не дописывайте) | 🩺 Советник · 1✉ |
| Спорная тема — где на самом деле правда? | вопрос как есть — получите карту согласий и расхождений без навязанного вывода | 🗺 Карта спора · 3✉ |
| Размытый вопрос: сами не знаете, чего хотите | вопрос как есть — сначала получите уточняющие вопросы | ❓ Уточнение · 2✉ |
| Логотип, схема, открытка, иллюстрация | «Нарисуй [что и в каком стиле]» — два векторных эскиза на выбор | 🎨 Картинка · 2–3✉ |
| Фото документа, вывески, меню | Поделиться фото → Poly Photo (OCR сделает всё сам) | Poly Photo (спутник) |
| Маленький экран / на ходу | спросите голосом — ответ прочитается вслух, а текст ляжет в буфер | Poly Voice (спутник) |
| Не знаете, какой режим выбрать | вопрос как есть — не выбирайте режим сами | 🧭 Авто · +1✉ (ChatGPT подберёт режим; Duo перезапустится с тем же вопросом) |
| Лимит сообщений жмёт, а нужен «взгляд двоих» | вопрос как есть | ➕ Дельта · 2✉ (дешёвая альтернатива 🔀 Синтезу: якорь Claude + список усилений ChatGPT — 2 сообщения вместо 3) |

## Приёмы

- **Дебаты — редкость, не дефолт.** Держите их для случаев «нужно, чтобы второй специально сломал вывод»: критичный код, решение с высокой ценой ошибки. Обычное письмо — Критика или Советник; высокие ставки — Синтез.
- **Почему ИИ отвечают, пока не видели друг друга.** Проверяющий, который уже прочитал ответ, склонен с ним соглашаться, даже если сам к нему не пришёл бы. Поэтому в ⚖️ Критике, 👀 Опросе, 🔀 Синтезе и в спорах каждый ИИ сначала отвечает сам, и только потом ответы сравниваются. Если два ответа совпали так, это весит больше, чем согласие после прочтения. ➕ Дельта и ✍️ Claude пишет, ChatGPT проверяет — это редактура и дополнения, а не проверка фактов.
- **Клавиша-микрофон** на клавиатуре в окне вопроса — голосовой ввод без настройки.
- **Слова-модификаторы** в конце вопроса работают: «отвечай сжато», «развёрнуто», «только по пунктам» — модели их слушаются.
- Для повторяющегося сценария можно сделать **отдельную мини-команду**: блок текста с уже готовым заданием, а за ним «Запустить команду» на Duo (задание станет предзаполненным вопросом).
- Итог каждого прогона уже лежит в **буфере обмена** — вставляйте сразу в письмо или чат — и сохранён в **журнале**, `Duo-journal.md`.
