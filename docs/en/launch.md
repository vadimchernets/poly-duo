# Ask C1M Duo without opening anything

Duo is a shortcut, so iPhone can start it from almost anywhere. Pick one or two of these. Each
takes under a minute to set up, and you only do it once.

**Tip that works everywhere:** copy the text you want checked first. If you start Duo without
sharing anything, the question box comes up with what you copied already in it.

| Where | How to set it up | Works on |
|---|---|---|
| **"Hey Siri, Duo"** | Nothing to set up: Siri knows the shortcut by its name. Keep the name «Duo». | any iPhone, iOS 18+ |
| **Share button** | Select text in any app → Share → **Duo**. Already on. | any iPhone, iOS 18+ |
| **Double-tap the back of the phone** | Settings → Accessibility → Touch → **Back Tap** → Double Tap → **Duo**. | iPhone 8 and newer |
| **Control Center** | Open Control Center → **+** (top left) → Add a Control → **Shortcuts** → choose **Duo**. | iOS 18+ |
| **Lock Screen button** | Touch and hold the Lock Screen → Customize → Lock Screen → tap a bottom button → **Shortcut** → **Duo**. | iOS 18+ |
| **Action Button** | Settings → **Action Button** → swipe to **Shortcut** → **Duo**. | iPhone 15 Pro and newer |
| **Home Screen icon** | Shortcuts app → touch and hold **Duo** → Share → **Add to Home Screen**. | any iPhone |
| **Mac or iPad** | The final answer is also in the shared clipboard: press Cmd+V on your Mac. | same Apple ID, Handoff on |

## Check a screenshot with two AIs

Take the screenshot, tap its preview, touch and hold the text (Live Text) → **Select All** → Share →
**Duo**. Works on any iPhone with iOS 18.

iOS 27 can also start a shortcut by itself when you take a screenshot: Shortcuts app →
**Automation** → **+** → **Screenshot** → **Run Shortcut** → **Duo**. This has not been tried on a
phone yet.
