# Our own check of the pair (26 Oct 2026)

Two rounds of a blind measurement of what the Claude review does to ChatGPT's draft. Raw data, prompts,
judge verdicts and scripts are in `round-1/` and `round-2/`. The original reports (in Russian) are
the single `.ru.md` file in each of `round-1/` and `round-2/`; every number below is taken from them.

## Method

- **Models, through command-line tools, not the phone apps.** ChatGPT = `codex exec -m gpt-5.6-sol -s read-only`.
  Claude = `claude -p --model sonnet`. One attempt per task. In round 2 Claude ran with tools switched off.
- **Variants.** A: ChatGPT answers alone. C: Claude answers alone, blind. D: Duo Critique (Claude checks A; the product's result).
  B: Duo "blind first" (Claude gets the Critique prompt plus its own earlier blind answer C, then writes the result).
- **Prompts** are frozen in `prompts/` (`wrap.txt`, `critique.txt`) and identical for the whole run.
- **Tasks** have a reference answer and a criterion, written before the run.
  Round 1: 67 tasks (15 ordinary, 15 with a trap, 10 everyday, 15 harder multi-step, 12 aimed at known model weaknesses;
  27 were added after the first pass). Round 2: 108 candidates recorded before any run (84 generated by a seeded script with the
  answer computed in Python, 24 written by hand); the 23 where ChatGPT was wrong plus 23 random ones where it was right were kept (46).
- **Blind grading.** Answers appear under letters in random order, no names. Judges: Kimi and Claude Opus in a cold session.
  They agreed on 266 of 268 grades (round 1) and 184 of 184 (round 2). In round 1, five answers whose first line was wrong and
  was corrected further down were counted as "partial" (not correct); both counts are in the data.
- Strict scoring: only "correct" counts. Intervals are 95% Wilson; the B-versus-D test is exact McNemar.

## Round 1: 67 tasks, ChatGPT is rarely wrong

| Variant | All 67 | Ordinary 15 | Trap 15 | Everyday 10 | Harder 15 | Weakness 12 |
|---|---|---|---|---|---|---|
| A ChatGPT alone | 66/67 = 99% [92-100] | 15/15 | 15/15 | 10/10 | 14/15 | 12/12 |
| C Claude alone | 62/67 = 93% [84-97] | 15/15 | 14/15 | 9/10 | 12/15 | 12/12 |
| D Duo Critique | 67/67 = 100% [95-100] | 15/15 | 15/15 | 10/10 | 15/15 | 12/12 |
| B Duo blind first | 67/67 = 100% [95-100] | 15/15 | 15/15 | 10/10 | 15/15 | 12/12 |

Judges only, without the first-line adjustments: A 67/67, C 64/67 = 96% [88-98], D 67/67, B 67/67.

- Made a correct draft wrong: 0 of 66 for D and for B (95% CI 0-6%).
- Fixed a wrong draft: 1 of 1 for D and for B (the one wrong draft, h15: the first line said "Saturday", the answer further down said Tuesday).
- Capitulation (Claude blind right, ChatGPT wrong, result repeats ChatGPT): 0 of 0, not measurable, because that case never occurred.
- B versus D: 0 and 0 disagreements, p = 1.0, no difference established.
- Where the blind Claude was wrong and ChatGPT right (4 tasks), B chose ChatGPT's correct answer each time.
- Median length in words: A 19, C 119, D 81, B 93.

## Round 2: tasks chosen because ChatGPT got them wrong

This set is selected against ChatGPT. It measures what the pair does once ChatGPT has already erred. It does **not** measure how often
ChatGPT errs: its 50% here comes from the selection. Main analysis: 38 tasks, the 46 minus 8 where Claude, with tools off, printed a tool call
instead of an answer (an artefact of the test rig).

| Variant | All 38 | ChatGPT wrong (18) | Control, ChatGPT right (20) |
|---|---|---|---|
| A ChatGPT alone | 20/38 = 53% [37-68] | 0/18 | 20/20 |
| C Claude alone | 36/38 = 95% [83-99] | 17/18 | 19/20 |
| D Duo Critique | 37/38 = 97% [87-100] | 18/18 | 19/20 |
| B Duo blind first | 36/38 = 95% [83-99] | 17/18 | 19/20 |

All 46 tasks, the artefact counted as a wrong answer: A 23/46 = 50% [36-64], C 38/46 = 83% [69-91], D 40/46 = 87% [74-94], B 37/46 = 80% [67-89].

- Repair (ChatGPT wrong, result right): D 18/18 (95% CI 82-100%), B 17/18 (74-99%).
- Harm (ChatGPT right, result wrong): D 1/20 and B 1/20 (CI up to 24%), the same task (h07, a riddle with an ambiguous reading:
  the review blurred a correct answer for completeness). On all 46: D 1/23, B 3/23, two of the three being the tool-call artefact.
- Capitulation: 0 of 17 for D and for B. In these tasks ChatGPT's errors are computational (calendar, percentages, characters, modular
  arithmetic), which Claude simply recomputes; a judgement question where the answer cannot be recomputed is not tested.
- B versus D: 0 against 1, p = 1.0 (38 tasks); 0 against 3, p = 0.25 (46 tasks, all three against B). Not established.
- One case where B repeated its own blind error (q02, a percentage chain); D recomputed it correctly. One case, no conclusion drawn.
- Claude alone is nearly as good as the pair here (36/38 against 37/38): on this set the pair mostly means Claude recomputed the answer.
  An advantage of Duo over Claude alone is not shown.

## What this supports

The review almost never damages a correct draft (round 1: 0 of 66; round 2, 1 of 20 on a deliberately small control). When ChatGPT was
wrong, the Claude review fixed it in 18 of 18 cases, on computational errors. A difference between the blind variant and the earlier
Critique is not established (p = 1.0; on 46 tasks p = 0.25, three disagreements, all against the blind variant). Anchoring on
the draft could not be tested on these sets.

## Limits

1. Command-line models, not the phone apps. The apps may run code, and the free ChatGPT app is probably weaker than `gpt-5.6-sol`.
2. One attempt per task; the spread between runs is not measured, and Claude's reply language changed from call to call.
3. Round 1 is too easy for these models (ChatGPT wrong once in 67); it shows the pair does not harm, not how often it catches real mistakes.
4. Round 2 was selected against ChatGPT; its accuracy figures say nothing about ChatGPT's real error rate. The control half is small.
5. Errors in round 2 are mostly computational, so the result does not carry over to judgement questions.
6. The second judge (Claude Opus) is from the same family as the answering Sonnet; judges from other families were unavailable.
   Blinding is incomplete: a review reads as a review.
7. Claude ran without tools in the CLI; 8 of 46 round-2 tasks returned a tool call instead of an answer (both counts are given).
8. Language drift: Claude answered a question in English in Russian in 7 of 67 blind answers (C), 7 of 67 (B), 2 of 67 (D); ChatGPT in 1.
9. Intervals are wide; the sets are small.

## Files

- `round-1/`, `round-2/`: `tasks*.json`, `prompts/`, `raw/<id>.<A|B|C|D>.txt` with `.prompt` (the exact request), `judge/` (verdicts,
  letter-to-variant maps), `stand.ru.py` (`run` / `judge` / `score`), `score.ru.py`, `score_output.txt` and the other score outputs, run logs.
- **File names with `.ru`.** The repository allows Cyrillic only in files marked `.ru.`. Any raw, judge, script or log file that contains
  Russian text (model answers in Russian, comments, the original reports) therefore carries `.ru` before its extension, for example
  `t05.C.ru.txt`, `stand.ru.py`. The scripts still refer to the original names without `.ru`, so to re-run them, strip `.ru` from those names.
- Absolute paths and the user name were replaced: `<stand>/round-1`, `<stand>/round-2`, `~`. The data contains no keys or tokens.
